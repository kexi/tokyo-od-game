# 歩行者用テクスチャ仕様書 (Pedestrian Textures)

Tokyo Open Drive の歩行者モデル（低ポリゴン・群衆表示対応）で使用する部品別テクスチャ一覧です。  
すべて `scripts/textures/human_textures.py` により手続き的（Procedural）に生成され、乱数シード固定により完全な再現性を保持しています。

ゲーム実行時に肌・服・ズボン・髪のマテリアル色（Diffuse/Albedo）を乗算（Multiply）して人ごとのカラーバリエーションを表現するため、肌・シャツ・ズボン・髪のテクスチャは「白（#FFFFFF）を基調としたグレースケール（RGB）」で陰影・縫い目・テクスチャ感のみを記録しています。靴のみフルカラーテクスチャです。

---

## 1. 生成ファイル一覧

| ファイル名  | 寸法 (px) | カラー形式 | 容量   | 用途 / UVマッピング                                                     |
| :---------- | :-------- | :--------- | :----- | :---------------------------------------------------------------------- |
| `face.png`  | 512 × 512 | RGB (sRGB) | ~11 KB | 頭部前半分正面平行投影（白地基調、眉・目・鼻陰影・口、アニメ調回避）    |
| `shirt.png` | 512 × 512 | RGB (sRGB) | ~72 KB | 左半分が前面（襟・前立てボタン・胸ポケット）、右半分が背面、下端1/8袖口 |
| `pants.png` | 512 × 256 | RGB (sRGB) | ~28 KB | 脚円筒展開（横方向シームレス、ウエストバンド・ベルトループ・膝しわ）    |
| `hair.png`  | 256 × 256 | RGB (sRGB) | ~9 KB  | 毛流れ（縦横2次元完全シームレスタイリング、白地ハイライト＋陰影）       |
| `shoes.png` | 256 × 128 | RGB (sRGB) | ~5 KB  | スニーカー側面円筒展開（横方向シームレス、濃色アッパー＋白ソール）      |

※ すべてのテクスチャは 150KB 以下（最大でも ~72KB）に最適化されています。

---

## 2. 生成方法・アルゴリズム詳細

- **生成環境**: Python (Pillow + NumPy) による完全手続き的生成。
- **再現性**: 乱数シードを固定（`SEED = 42`）し、再実行時にビット単位で同一の出力を保証。
- **外部画像素材**: 一切不使用（写真・AI画像不使用）。
- **フォント**: フォントファイルへの依存なし（ベクター幾何描画）。

### 各テクスチャの設計詳細

1. **`face.png` (512 × 512)**:
   - 頭部の前半分を正面から平行投影。中心 $(256, 256)$ が顔の中心、画像の端が頭の輪郭（半径 256px）。
   - 目は $v = 0.55$（$y \approx 230\text{px}$）、口は $v = 0.30$（$y \approx 358\text{px}$）。
   - 白（255）を基調とし、眉・瞳（白目を描かない落ち着いたダークグレー）・鼻下の陰影・口・微細な輪郭減衰を低ポリゴン歩行者に適した簡素な階調で配置。
2. **`shirt.png` (512 × 512)**:
   - 左半分（$u: 0.0 \sim 0.5$）が胴体前面、右半分（$u: 0.5 \sim 1.0$）が背面。
   - $v = 0$ が裾、$v = 1$ が首まわり。
   - 前面: 襟ぐり、中央の前立てとボタン（4つ穴＋糸ステッチ）、左胸のパッチポケットとステッチ。
   - 背面: 浅い首ぐり、ショルダーヨーク切り替え線、中央の背中心縫い目。
   - 下端 1/8（$y: 448 \sim 512\text{px}$）: 袖口パーツとして無地ベース＋袖口折り返しステッチ。
   - 全体にオックスフォード調の細かい縦横織り目（Fabric Weave）を微細な濃淡で付与。
3. **`pants.png` (512 × 256)**:
   - 脚部円筒展開テクスチャ。$u$ 軸（横 512px）で左右端がシームレスに結合（周期境界）。
   - $v = 0$ が裾、$v = 1$ がウエスト。
   - 上端（$y: 0 \sim 38\text{px}$）にベルトループ（等間隔4箇所配置、左右端はラップアラウンド）付きウエストバンド。
   - 膝付近（$v \approx 0.5$, $y \approx 128\text{px}$）に周方向シームレスな綾織り（Twill）と膝の屈伸しわ（Wrinkles）。
   - 脇縫い目（サイドシーム）と内股縫い目（インシーム）のダブルステッチ。
4. **`hair.png` (256 × 256)**:
   - 4次元トーラスマッピングによる $u, v$ 縦横2次元完全シームレスタイリング。
   - 周期的な多重フーリエ周波数による毛束・毛流れの微細繊維と、中央付近のハイライト（Sheen）バンド。
5. **`shoes.png` (256 × 128)**:
   - スニーカー側面円筒展開（横方向シームレス）。
   - チャコールネイビーのメッシュ/キャンバスアッパー、ホワイトミッドソール、ライトグレートレッドアウトソール。
   - トゥキャップ、スポーティーなサイドストライプ、ヒールカウンター、ミッドソールの屈曲溝（フレックスグルーブ）。

---

## 3. 再生成コマンド

```bash
# テクスチャ生成（assets/human/textures/ 配下に出力）
uv run scripts/textures/human_textures.py

# コンタクトシート（一覧プレビュー画像）を書き出す場合
uv run scripts/textures/human_textures.py /path/to/preview.png
```

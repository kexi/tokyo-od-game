# 車両用テクスチャ仕様書 (Vehicle Textures)

Tokyo Open Drive の車両モデル（コンパクトハッチバックおよびタクシー仕様）で使用する部品別テクスチャ一覧です。  
すべて `scripts/textures/car_textures.py` により手続き的（Procedural）に生成され、乱数シード固定により完全な再現性を保持しています。

---

## 2. 生成方法・アルゴリズム詳細

- **生成環境**: Python (Pillow + NumPy) による完全手続き的生成。
- **再現性**: 乱数シードを固定（`SEED = 42`）し、再実行時にビット単位で同一の出力を保証。
- **外部画像素材**: 一切不使用。
- **AI画像生成**: 不使用（完全なコードベース幾何・数学的手続き生成）。

### 各テクスチャの設計詳細

1. **`plate_private.png` / `plate_commercial.png`**:
   - 日本の自動車登録番号標（330 × 165 mm, 比率 2:1）に準拠。
   - 上段（地名「品川」・分類番号「330」「500」）、下段（平仮名「さ」「あ」・一連指定番号「12-34」「56-78」）。番号はすべて架空。
   - 左上に「東」の文字が刻まれた封印キャップ、右上にプラスネジ式固定ボルト、文字エンボス凸凹陰影を配置。
2. **`taxi_sign.png`**:
   - 内照式アクリル特有の温かみのある中心光グラデーションと、外周の保護ベゼル枠。
   - 太字の「TAXI」および汎用的な「個人」表記。実在するタクシー会社の商標・意匠は不使用。
3. **`vacancy_sign.png`**:
   - 64 × 16 ドットマトリクスLEDによる高輝度赤色「空車」表示。
   - 点灯LEDの芯（白熱）＋発光グロー（ブルーム）と、消灯LEDの暗いグリッド構造を再現。
4. **`tire_tread.png`**:
   - 4本の主溝（周方向ストレートグルーブ）と斜めサイプ・ショルダーブロック。
   - 高さマップ（Heightmap）から法線勾配を計算した立体陰影処理。X軸方向（0〜512px）で周期境界を満たし、横方向に完全シームレス。
5. **`tire_sidewall.png`**:
   - ホイールリム内側（半径 $r < 135\text{px}$）およびタイヤ外周（半径 $r > 245\text{px}$）を完全透明化。
   - 極座標変換による円弧状テキスト配置（上部「TOKYO OPEN DRIVE」、下部「185/65R15 88H • RADIAL」）。
6. **`headlight.png`**:
   - 濃色インナーハウジング、同心円切削プロジェクターレンズ（ブルー光学コーティング反射）、L字型LEDデイタイムランニングライト（DRL）、マルチリフレクターファセット。
7. **`taillight.png`**:
   - 流麗なC字型LED導光バー、ルビーレッドのリフレクターステップ、ウインカー（アンバー）・バックランプ（クリア）のコンビネーション。
8. **`grille.png`**:
   - 六角形セルが $256 \times 256\text{ px}$ で $8 \times 8$ 周期で並ぶように配置し、縦横シームレスタイリングを実現。六角形の穴部は完全透明（$\alpha = 0$）。

## 3. 使用フォントとライセンス

文字はすべて **Noto Sans JP**（SIL Open Font License 1.1）で描いています（漢字・仮名・英数字とも）。フォントファイルはリポジトリに入れず、生成スクリプトが google/fonts のコミット `295d98a7a0c17c68f1341eaeea354e7960ea70d3` の `ofl/notosansjp/NotoSansJP[wght].ttf` を取得し、SHA-256（`c2f3b4d4…0fc68f`）を照合してから使います。キャッシュ先は `${XDG_CACHE_HOME:-~/.cache}/tokyo-od-game/fonts/`。

取得や照合に失敗したときは止まります。macOS のシステムフォント（ヒラギノ、Helvetica など）は再配布の条件が明確でないため、代わりに使うことはしません。初版は「TAXI」とタイヤ側面の英数字を Helvetica で描いていたため、Noto Sans JP で描き直しました。

## 4. 再生成手順

リポジトリルートで次を実行します。引数に PNG のパスを渡すと、確認用のコンタクトシートも書き出します。

```bash
just car-textures            # = uv run scripts/textures/car_textures.py
uv run scripts/textures/car_textures.py /tmp/textures-preview.png
```

制作は Antigravity（agy）への委譲で行い、フォントの扱いとプレビュー出力先を Claude Code が修正しました。

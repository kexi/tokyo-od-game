# 救急車用テクスチャ仕様書 (Ambulance Textures)

Tokyo Open Drive の高規格救急車（白いハイルーフのワンボックス型緊急車両、全長 5.6m・全高 2.5m）で使用するデカールおよび赤色警光灯レンズテクスチャ一覧です。  
すべて `scripts/textures/ambulance_textures.py` により手続き的（Procedural）に生成され、乱数シード固定により完全な再現性を保持しています。

---

## 1. 生成ファイル一覧

| ファイル名               | 寸法 (px)  | カラー形式  |   容量   | 用途 / マッピング                                                                        | 発光マップ兼用  |
| :----------------------- | :--------- | :---------- | :------: | :--------------------------------------------------------------------------------------- | :-------------: |
| `ambulance_side.png`     | 1024 × 256 | RGBA (sRGB) | ~7.2 KB  | 車体側面デカール（太帯・細帯・「救急」「AMBULANCE」表記、透明背景）                      |      なし       |
| `ambulance_hood.png`     | 512 × 128  | RGBA (sRGB) | ~5.3 KB  | ボンネット用デカール（前方車両のバックミラー視認用 鏡文字「救急」、透明背景）            |      なし       |
| `ambulance_rear.png`     | 512 × 256  | RGBA (sRGB) | ~6.0 KB  | 後面ドア用デカール（バックドア赤帯・「救急」「AMBULANCE」、透明背景）                    |      なし       |
| `ambulance_lightbar.png` | 256 × 64   | RGBA (sRGB) | ~33.1 KB | ルーフ赤色散光式警光灯レンズ（ルビーレッド樹脂・8連LED発光素子・パラボラ反射板、不透明） | あり (Emissive) |

※ すべてのテクスチャは 150KB 以下（最大 ~33KB）に最適化されています。  
※ 車体塗装（白）はシェーダー・マテリアルで表現するため、デカール（1〜3）は赤帯と文字部分のみを描画し、それ以外は完全透過（$\alpha = 0$）です。

## 2. 生成方法・アルゴリズム詳細

- **生成環境**: Python (Pillow + NumPy) による完全手続き的生成。
- **再現性**: 乱数シードを固定（`SEED = 42`）し、再実行時にビット単位で同一の出力を保証。
- **外部画像素材**: 一切不使用。
- **AI画像生成**: 不使用（コードベースの幾何学的・光学的モデリングによる手続き生成）。

### 各テクスチャの設計詳細

1. **`ambulance_side.png` (1024 × 256)**:
   - 日本の高規格救急車の標準的なサイドストライプ配置。
   - 高さ方向の中ほどにエマージェンシーレッド（`#D7262E`）の太帯（$y = 136 \sim 180\text{px}$）と、その下に間隔を空けて細帯（$y = 194 \sim 206\text{px}$）を全幅に配置。
   - 前方寄り（左側）に大きく太字の「救急」（Noto Sans JP Bold, 72px）、その下に「AMBULANCE」（Noto Sans JP Bold, 24px, トラッキング付き）を配置。
   - 左右側面の両方へ文字が正しく読める向きで貼る前提（ゲーム側で UV を左右反転マッピングするため、テクスチャ自体は標準向き）。

2. **`ambulance_hood.png` (512 × 128)**:
   - ボンネット中央に配置する鏡文字（水平反転）の「救急」マーキング。
   - 緊急走行時に前方を走行する自動車のルームミラー（バックミラー）越しに正像として視認できるようにする実車の仕様を再現。

3. **`ambulance_rear.png` (512 × 256)**:
   - 後面バックドア用デカール。
   - 中央配置の「救急」「AMBULANCE」と、バックドア下部を横断する太帯・細帯の組み合わせ。

4. **`ambulance_lightbar.png` (256 × 64)**:
   - ルーフ上に設置される赤色散光式警光灯（LEDバーライト）のレンズ。
   - 深みのあるクリアレッド樹脂（ルビーレッドの縦方向グラデーションおよび微細なフレネル屈折縦リブ）、上下ハウジング境界のベゼルシャドウ。
   - 8基の独立した高輝度LED発光ダイオードモジュール（白熱の中心ホットスポット、鮮烈なクリムゾングロー、集光パラボラ反射板カップ、段付き同心プリズムリング）。
   - 夜間はそのまま発光マップ（Emissive Texture）として適用可能。

## 3. 法的制約・商標への配慮

- **赤十字標章の不使用**: 「赤十字の標章及び名称等の使用の制限に関する法律」を遵守し、白地に赤い十字（ジュネーブ条約標章）および類似記章（スター・オブ・ライフ等含む）は一切描画していません。
- **組織名・商標の排除**: 実在の自治体・消防本部組織名（東京消防庁等）、紋章・ロゴ・電話番号などは使用せず、汎用的な「救急」「AMBULANCE」の文字のみで構成しています。

---

## 4. 使用フォントとライセンス

文字はすべて **Noto Sans JP**（SIL Open Font License 1.1）のみを使用しています。  
フォントは `scripts/textures/car_textures.py` の `get_noto_font()` を再利用し、google/fonts のコミット `295d98a7a0c17c68f1341eaeea354e7960ea70d3` の `ofl/notosansjp/NotoSansJP[wght].ttf` を取得後、SHA-256（`c2f3b4d4…0fc68f`）を検証して利用します。システムフォントへのフォールバックは禁止されています。

---

## 5. 再生成手順

リポジトリルートで次を実行します。

```bash
uv run scripts/textures/ambulance_textures.py
```

確認用のコンタクトシート（透過度確認チェッカーボード付き）を書き出す場合は、第1引数に出力先パスを渡します：

```bash
uv run scripts/textures/ambulance_textures.py /tmp/ambulance-textures-preview.png
```

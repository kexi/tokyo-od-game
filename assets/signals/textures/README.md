# 交通信号灯器テクスチャ仕様書 (Traffic Signal Textures)

『法令厳守 TOKYO OPEN DRIVE』の信号機モデル（車両用・歩行者用灯器）で使用するレンズおよびピクトグラムテクスチャ一式です。  
すべて `scripts/textures/signal_textures.py` により手続き的（Procedural）に生成され、乱数シード固定により完全な再現性を保持しています。

---

## 1. 生成ファイル一覧

| ファイル名     | 寸法 (px) | カラー形式  | 容量   | 区分         | 用途 / 仕様説明                                                                                                            |
| :------------- | :-------- | :---------- | :----- | :----------- | :------------------------------------------------------------------------------------------------------------------------- |
| `lens_led.png` | 256 × 256 | RGBA (sRGB) | ~72 KB | 車両用灯器   | 円形LED信号レンズ（六角格子配列のLED素子群、拡散板ベース、周辺減光、外枠リム）。外側は透過（$\alpha=0$）。                 |

| `ped_go.png`   | 256 × 256 | RGBA (sRGB) | ~25 KB | 歩行者用灯器 | 「進め」（青/緑）ピクトグラム。左向きに歩行中の人物シルエット（LEDドットテクスチャ付）と角丸正方形拡散板バックグラウンド。 |

## 2. ゲームエンジン (Three.js) での利用設計

本テクスチャはシェーダ側で動的に発光色（赤・黄・青/緑）を乗算・制御できるよう、**グレースケール（輝度）およびアルファマスク**として設計されています。

- **カラーマップ / エミッシブマップ兼用**:
  - `RGB` チャンネル: 白色（高輝度）〜 拡散板（低輝度）のグレースケール輝度値。
  - ゲーム内マテリアルで `color` / `emissive` に各信号色（例: 赤 `#FF1E1E`, 黄 `#FFC814`, 青/緑 `#14EB8C`）を乗算して発光・消灯状態を表現します。
- **アルファチャンネル**:
  - `lens_led.png`: レンズ円形領域の内側 $\alpha = 1$、外側 $\alpha = 0$（アンチエイリアス処理済）。
  - `ped_stop.png` / `ped_go.png`: 角丸正方形の灯器面内側 $\alpha = 1$、外側 $\alpha = 0$。

---

## 3. ピクトグラムの権利・意匠方針

- 歩行者用信号灯器の「人の形」ピクトグラムは、日本の標準的な交通信号機灯器の形状を参考にした一般的な幾何学的描画（Generic drawings of standard shapes）です。
- 特定の団体名、ロゴ、商標、著作権保護対象となるデザインの模倣は一切含まれていません。

---

## 4. 生成・再生成コマンド

```bash
# 全テクスチャの生成（assets/signals/textures/ 配下に出力）
uv run scripts/textures/signal_textures.py

# 確認用コンタクトシート（着色シミュレーション含む）を出力する場合
uv run scripts/textures/signal_textures.py /tmp/signal-preview.png
```

# バイク（軽二輪 250 cc）用テクスチャ

`scripts/textures/motorbike_textures.py` が手続き生成する（`uv run scripts/textures/motorbike_textures.py [確認用シート.png]`）。モデルは `scripts/blender/motorbike.py`。外部画像・AI 画像生成は使っていない。

| ファイル              | 寸法      | 用途                                                                                                                                                                                                                        |
| :-------------------- | :-------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `motorbike_plate.png` | 460 × 250 | 後部のナンバー（230 × 125 mm を 2 px/mm）。道路運送車両法施行規則 第14号様式（軽二輪）の配置: 上段に分類番号・地名・ひらがな、下段に一連番号。自家用なので白地に緑文字で、縁取りは無い（緑の縁取りは小型二輪＝251 cc 以上） |
| `motorbike_wheel.png` | 512 × 256 | 左半分が 10 本スポークのキャストホイール、右半分が穴あきブレーキディスク。どちらも隙間はアルファ 0（glTF の MASK）                                                                                                          |

- 二輪のナンバーは後面だけ。番号「1 品川 さ 47-19」は架空。「さ」は軽二輪の自家用に割り当てられた 39 字の一つ（事業用は り・れ、貸渡は わ。国土交通省「二輪車のナンバープレートの現状等について」）。
- 文字はコミット固定の Noto Sans JP（SIL OFL 1.1）。ナンバーの文字は様式の枠（数字 35 × 60 mm など）に合わせて縦横に伸ばしている。
- 車体・ヘルメット・ライダーの服は無地の材質で、テクスチャを持たない。メーカーのロゴは描いていない。

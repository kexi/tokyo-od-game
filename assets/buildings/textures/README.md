# 建物外壁テクスチャ仕様書 (Building Facade Textures)

Tokyo Open Drive における国土交通省 PLATEAU LOD1 建物モデル向けの外壁テクスチャ一式です。  
すべて `scripts/textures/building_textures.py` により手続き的（Procedural: Python + Pillow / NumPy）に生成され、乱数シード固定（`SEED = 42`）により完全な再現性を保持しています。

---

## 1. テクスチャ寸法とタイリング仕様

- **解像度**: $512 \times 560\text{ px}$（幅 512px × 高さ 560px）
- **スケール**: 1px あたり 2.5cm（$0.025\text{ m}$）
  - **幅**: $12.8\text{ m} = 512\text{ px}$（柱間 $3.2\text{ m} = 128\text{ px} \times 4\text{ スパン}$）
  - **高さ**: $14.0\text{ m} = 560\text{ px}$（階高 $3.5\text{ m} = 140\text{ px} \times 4\text{ 階分}$）
- **タイリング方式**:
  - シェーダー側でワールド座標または UV スケーリング（壁の水平長・高さ）に基づきリピート配置されます。
  - 上下左右の端部境界は完全周期（Toroidal wrap）設計となっており、目立つ継ぎ目なしに無限タイリングが可能です。

## 3. マスクテクスチャ仕様 (`facade_<style>_mask.png`)

- **フォーマット**: 8-bit グレースケール (`L`)
- **値の定義**:
  - `255` (白): 窓ガラス（夜間の窓明かり発光 Emissive、および鏡面反射を強く適用）
  - `48` (暗い中間値): スパンドレルガラス等の不透明反射素材（夜間は発光せず、昼間の環境マップ反射のみ適用）
  - `0` (黒): 外壁・柱・手すり・窓枠・室外機・配管（窓明かり非発光）

---

## 4. 生成方法・アルゴリズム

- **完全手続き的生成**: 外部の写真素材や AI 画像生成は一切使わず、Python（Pillow + NumPy）の幾何学的描画・数学モデルにより生成。
- **フーリエ変換（FFT）による周期的シームレスノイズ**: `seamless_fractal_noise()` により、外壁の微細な質感や汚れをトーラス状周期境界で生成。
- **周期的法線勾配シェーディング**: 高さマップ（Heightmap）から周期的 Sobel フィルタ（`np.roll`）を用いて法線ベクトルを算出し、自然な光線陰影（ランバート拡散反射）を合成。
- **再現性**: 固定乱数シード（`SEED = 42`）により、何度実行しても同一のバイナリを出力。

## 5. 再生成・検証コマンド

```bash
# テクスチャの再生成
uv run scripts/textures/building_textures.py

# コンタクトシート（3×3 タイル検証用画像）の生成
uv run scripts/textures/building_textures.py /tmp/building_contact_sheet.png
```

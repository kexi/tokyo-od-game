# トラック用テクスチャ（10t 級ウイング車・8t 増トン平ボディ）

`scripts/textures/truck_textures.py` が手続き生成する（`uv run scripts/textures/truck_textures.py [確認用シート.png]`）。モデルは `scripts/blender/truck.py`（`10t` / `8t` の 2 種）。外部画像・AI 画像生成は使っていない。

| ファイル           | 寸法       | 用途                                                                                                                                                                      |
| :----------------- | :--------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `truck_box.png`    | 256 × 512  | アルミウイング荷台の側板 1 m 分。横方向に繰り返して貼る（u がメートル）。上端の上部レール、下部のアオリ境界、下端のサイドレール                                           |
| `truck_decals.png` | 1024 × 512 | 「最大積載量 13,500kg」（0,0〜512,96）、「最大積載量 8,200kg」（0,96〜512,192）、大型後部反射器（512,0〜1024,128、赤と黄の斜め縞）、フロントグリル 2 種、ステップの縞鋼板 |
| `truck_plates.png` | 512 × 512  | 事業用の緑ナンバー（大板）。上半分が 10t 車「品川 100 か 58-26」、下半分が 8t 車「練馬 100 う 70-38」                                                                     |
| `truck_wheel.png`  | 512 × 256  | 白塗りスチールホイール（飾り穴 8・ナット 10）とタイヤのゴム                                                                                                               |

アトラスの矩形は `truck.py` の `DECALS` / `PLATES` と同じ値を持つ。

- 最大積載量は 保安基準 第18条第8項で車体の**後面**への表示が義務。ドアへの表示は慣行として描いた（同じ画像を使い回す）。
- 大型後部反射器は 保安基準 第38条の2（車両総重量 7 t 以上の貨物車）。縞の色は赤と黄で描いたが、反射性能・寸法の細目（告示）までは再現していない。
- メーカーのエンブレム・事業者名は入れていない。ナンバーは架空。
- 文字は Noto Sans JP（SIL OFL 1.1）のみ（`car_textures.py` の `get_noto_font()`）。ホイールの描画は `bus_textures.py` の `draw_wheel()` を共用する。

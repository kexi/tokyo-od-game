# 大型路線バス用テクスチャ

`scripts/textures/bus_textures.py` が手続き生成する（`uv run scripts/textures/bus_textures.py [確認用シート.png]`）。モデルは `scripts/blender/bus.py`。外部画像・AI 画像生成は使っていない。

| ファイル         | 寸法       | 用途                                                                                                                                                                                                  |
| :--------------- | :--------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bus_dest.png`   | 1024 × 256 | LED 行先表示器のアトラス。前面（0,0〜1024,160、4 px ピッチの 256 × 40 ドット）、側面（0,160〜512,256）、後面（512,160〜896,256）。材質 `Dest` の発光マップを兼ねる                                    |
| `bus_decals.png` | 2048 × 512 | 塗装帯（側面 0,0〜2048,320 は左端が車両前端、下端が地上 0.25 m・上端が 1.25 m）、前面・後面の裾、「ノンステップバス」「入口」「出口」「ワンマン」、機関室ルーバー。透過部はアルファ 0（glTF の MASK） |
| `bus_plate.png`  | 512 × 256  | 事業用の緑ナンバー（大板 440 × 220 mm、緑地に白文字）「品川 200 か 37-15」                                                                                                                            |
| `bus_wheel.png`  | 512 × 256  | 左半分がスチールホイールの正面（飾り穴 8・ナット 10）、右半分がタイヤのゴム（溝は周方向）                                                                                                             |

アトラスの矩形は `bus.py` の `DEST` / `DECALS` と同じ値を持つ。片方を変えたらもう片方も直す。

- 塗装は架空の配色（アイボリーに青緑の裾と珊瑚色の細線）。実在の事業者の塗装・社名・社章、実在の系統記号は使っていない。系統番号「41」と行先（地名のみ）は架空の組み合わせ。
- 車いすマーク（国際シンボルマーク）は使用条件があるため描いていない。
- ナンバーは架空の番号。事業用の分類番号 2（乗車定員 11 人以上の乗用）とひらがな「か」を使う。
- 文字は Noto Sans JP（SIL OFL 1.1）のみ。`car_textures.py` の `get_noto_font()` がコミット固定で取得し SHA-256 を照合する。LED の小さな文字は通常の太さで描く（太字はドットが潰れる）。

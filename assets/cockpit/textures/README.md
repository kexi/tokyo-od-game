# 車内（運転席）テクスチャ

自車の車内視点用モデル `public/models/cockpit.glb`（`scripts/blender/cockpit.py`）が使うテクスチャです。すべて `scripts/textures/cockpit_textures.py` が Pillow と NumPy で描きます。外部の画像素材は使っていません。文字は、コミットを固定した Noto Sans JP（SIL OFL 1.1）だけで描きます（`car_textures.get_noto_font`）。ロゴ・ブランド名・実在の車名は入れていません。

| ファイル               | 寸法 (px) | 用途                                                                                           |
| :--------------------- | :-------- | :--------------------------------------------------------------------------------------------- |
| `gauge_speed.png`      | 512 × 512 | 速度計（0〜180 km/h、20 km/h ごとに数字）。発光マップも兼ねる                                  |
| `gauge_tacho.png`      | 512 × 512 | 回転計（0〜8 ×1000 r/min、6,500 r/min からレッドゾーン）。発光マップも兼ねる                   |
| `gauge_small.png`      | 512 × 256 | 左半分が燃料計（E〜F）、右半分が水温計（C〜H）                                                 |
| `telltales.png`        | 512 × 128 | 警告灯の記号。左から方向指示（左・右、緑）、走行用前照灯（青）、駐車ブレーキ（赤）。発光マップ |
| `hvac_panel.png`       | 512 × 256 | 空調パネル（温度・風量・吹き出し口のつまみ、A/C・内気循環・デフロスタのボタン、ハザード）      |
| `shift_gate.png`       | 256 × 256 | シフトゲート（P R N D B）                                                                      |
| `fabric_seat.png`      | 256 × 256 | シート・ドアの布（タイル状に繰り返す）                                                         |
| `fabric_headliner.png` | 128 × 128 | 天井の布（タイル状に繰り返す）                                                                 |
| `plastic_grain.png`    | 256 × 256 | ダッシュボードのシボ（タイル状に繰り返す）                                                     |
| `speaker_grille.png`   | 128 × 128 | スピーカーの網（タイル状に繰り返す）                                                           |

## 計器の角度

角度は 12 時の方向を 0 として時計回りに測ります。`cockpit.py` もこの値を使います。

- 速度計と回転計は −120°（ゼロ）から +120°（最大）までの 240°。1 km/h あたり 4/3°、1 r/min あたり 0.03° です。
- 燃料計と水温計は −45°（E・C）から +45°（F・H）までの 90° です。
- 針の回転中心は画像の中心です。

## 再生成

```bash
uv run scripts/textures/cockpit_textures.py [確認用シート.png]
```

乱数はシードを固定しているので、何度実行しても同じ画像になります。

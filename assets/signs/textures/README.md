# 道路標識テクスチャ仕様書 (Traffic Sign Textures)

Tokyo Open Drive の道路標識モデル（Blender 制作の標識板）で使用する図柄テクスチャ一式です。  
すべて `scripts/textures/sign_textures.py` により手続き的（Procedural）に生成され、乱数シード固定およびフォントハッシュ照合により完全な再現性を保持しています。

## 2. 法的根拠と色彩・意匠仕様

すべての標識図柄は「道路標識、区画線及び道路標示に関する命令」別表第二（e-Gov 法令現行版）の規定および国土交通省「道路標識一覧」の基準に準拠しています。

### 色彩規定（別表第二 備考）

- **赤 (#D7262E / `(215, 38, 46)`)**: 規制標識の外枠・斜帯・一時停止地色等
- **青 (#0B4EA2 / `(11, 78, 162)`)**: 最高速度文字・指定方向外進行禁止地色・一方通行地色・横断歩道地色等
- **白 (#FFFFFF / `(255, 255, 255)`)**: 縁・文字・矢印・進入禁止横帯・最高速度地色等
- **黒 (#1A1A1A / `(26, 26, 26)`)**: 横断歩道ピクトグラム（歩行者シルエット及び横断歩道縞）

### 形状と透過仕様

- **円形標識 (512×512)**: 画像枠に内接する円形。四隅の外側は完全透明（$\alpha = 0$）。
- **逆三角形標識 (512×512)**: 上辺が $y=0$、下端頂点が $(256, 512)$。逆三角形の外側は完全透明（$\alpha = 0$）。
- **正方形標識 (512×512) / 長方形標識 (256×512)**: 全面描画。

## 3. 生成方法・アルゴリズム詳細

- **生成環境**: Python (Pillow + NumPy) による手続き的生成（Procedural Generation）。
- **アンチエイリアス処理**: 4 倍スケール（$2048 \times 2048$、長方形は $1024 \times 2048$）の高解像度バッファ上で幾何パス・ベクターポリゴンを描画し、最終的に `LANCZOS` リサンプリングでダウンサンプリングすることで、滑らかで高品質なアンチエイリアス境界を実現。
- **外部画像・AI 生成**: 不使用。

---

## 4. 使用フォントとライセンス

- **フォント**: [Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP)（Variable Font, SIL Open Font License 1.1）
- **固定コミット**: `google/fonts` コミット `295d98a7a0c17c68f1341eaeea354e7960ea70d3`
- **SHA-256 チェックサム**: `c2f3b4d463500a2ddcd3849cded1fceeb9fd6d1c32e6cbecd568453ba50fc68f`
- システムフォント（Hiragino、Helvetica 等）へのフォールバックは禁止し、厳格なハッシュ照合により全プラットフォームでの完全な描画一致を保証しています。

# TOKYO OPEN DRIVE

東京都オープンデータ × PLATEAU 3D 都市モデルで、東京 23 区を車で走り回る three.js 製の 3D ドライブ探索ゲームです。

**プレイ:** https://kexi.github.io/tokyo-od-game/

- 建物は国土交通省 PLATEAU の 3D 都市モデル（建築物 LOD1、23 区の全棟）を、走行地点の周辺からブラウザへ直接ストリーミングします。
- 地形は国土地理院の標高タイル（DEM5A/DEM10B）から生成し、Rapier 物理エンジンで車・建物・地面の当たり判定を取ります。
- 光の柱は東京都・各区のオープンデータにある実在スポット（文化財、名所、夜景スポット、都立施設、水飲みスポット、給水拠点、避難場所、都営交通の駅など）です。
- 都営バスはリアルタイム位置（公共交通オープンデータセンター）を元に走り、天気は気象庁アメダス（東京）の観測値を反映します。
- 時間帯は「リアル時刻／朝／昼／夕方／夜」から選べます（プリセットはその日の実際の太陽高度から決めています）。
- 車を降りて歩けます。歩行者に話しかけると、近くの実在スポットの方角と距離を教えてくれます。会話 AI（Gemma 4、端末内で実行）と音声（sanoTTS-jp）は任意で有効にできます。

## 開発

`nix develop`（direnv）で Node.js 24・pnpm・just・lefthook などが揃います。

```sh
just install    # 依存のインストール（公開 1 日未満のパッケージは入れない設定）
just dev        # 開発サーバ
just check      # 型・lint・整形・テスト・justfile・Actions の検査
just data       # オープンデータを取得して public/data を再生成（ライセンスゲート付き）
just build      # dist/ に本番ビルド
```

`main` に push すると GitHub Actions が GitHub Pages にデプロイします。

### 構成

| パス                    | 役割                                                                                                                  |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `src/geo/`              | WGS84・ECEF・ENU の変換、浮動原点（LocalFrame）、タイル座標、太陽位置                                                 |
| `src/world/`            | 地形（DEM→メッシュ＋trimesh コライダ）、PLATEAU 建物（3d-tiles-renderer＋コライダ＋窓のシェーダ）、空・天気、都営バス |
| `src/physics/`          | Rapier のレイキャスト車両                                                                                             |
| `src/game/`             | 車のモデル、カメラ、入力、POI、ミッション、ミニマップ、音、出典表示                                                   |
| `scripts/fetch-data.ts` | ビルド時のデータ生成。東京都カタログの CKAN API でライセンスを照会し、CC BY 4.0 以外なら停止します                    |

23 区の端から端まではおよそ 30km あり、地球の曲率で端では約 18m 沈みます。そのため車の付近を原点とするローカル座標を使い、1.5km 離れるたびに ECEF 経由で原点を付け替えています。

## データ出典

ゲーム内の「出典」画面（I キー）に、各提供元が指定する書式で全データの出典を載せています。概要は次のとおりです。

- **東京都オープンデータ**（CC BY 4.0）: 文化財一覧（東京都教育庁）、公共施設一覧（東京都デジタルサービス局）、都立スポーツ施設一覧（東京都スポーツ推進本部）、Tokyowater Drinking Station 一覧・給水拠点一覧データ（東京都水道局）、東京都防災マップ 避難所・避難場所一覧データ（東京都総務局）、観光情報（しながわ百景）（品川区）、映える夜景スポット（江東区）、名所・史跡（台東区）。
  - いずれも緯度経度と名称を抽出し、形式を変換して利用しています（改変）。
  - 東京都提供の「避難所、避難場所データ オープンデータ」を利用しています。
  - 台東区のデータを利用しています。
- **3D 都市モデル**: 出典：国土交通省 PLATEAUウェブサイト「3D都市モデル（Project PLATEAU）東京都」を加工して作成（PLATEAU サイトポリシー／公共データ利用規約 第1.0版）。
- **国土地理院**: 地理院タイル（全国最新写真（シームレス）、標高タイル）。地理院タイル（標高タイル（基盤地図情報数値標高モデル））を加工して地形を作成しています。タイルはリアルタイムに読み込むだけで、同梱・再配布はしていません。
- **公共交通**: 東京都交通局・公共交通オープンデータ協議会「東京都交通局 バスロケーション情報」「東京都交通局 バス停情報」「東京都交通局 駅情報」を改変して利用（CC BY 4.0）。公共交通オープンデータセンターが提供するデータで、正確性・完全性は保証されません。公共交通事業者への問い合わせはせず、[Issues](https://github.com/kexi/tokyo-od-game/issues) へお寄せください。
- **気象**: 出典：気象庁ホームページ（アメダス東京）を加工して作成。天候の表現は気象庁の予報・警報ではありません。
- **町丁・区の境界と人口**: 出典：政府統計の総合窓口（e-Stat）「国勢調査 令和2年 小地域（町丁・字等別）境界データ 東京都」を加工して作成（政府標準利用規約 第2.0版準拠）。現在地の表示、スポット座標の検証、歩行者の人数に使います。
- **ジオイド高**: EGM2008（NGA、パブリックドメイン。PROJ-data 経由）。
- **音声合成**: [sanoTTS-jp](https://github.com/ayutaz/sanoTTS-jp)（コードは MIT、モデルは LicenseRef-sanoTTS-jp-Model-1.0）。帰属表示 (A) とライセンス全文は `public/tts/` とゲーム内の出典画面にあります。
- **会話 AI（任意）**: Google Gemma 4 E2B（Apache License 2.0）。有効にした端末だけが Hugging Face から直接ダウンロードし、LiteRT-LM で端末内で実行します。

### 利用条件を確認して決めたこと

- 国土地理院のジオイド・モデル由来の値は配布しません。測量法の承認が必要になる可能性があるためで、パブリックドメインの EGM2008 を使っています。
- 「地理院 標準地図」を 3D 地形に貼る使い方は、承認申請が必要かもしれない境界にあたるので使いません。写真か PLATEAU オルソ画像だけを使います。
- 地理院タイルの出典は、表示中は常に画面下に出しています。
- 現在地の区・町丁は e-Stat の境界ポリゴンで判定し、国土地理院の逆ジオコーダは呼びません。気象庁の JSON は 10 分ごとに 1 回までに抑えています。
- 元データの座標誤りは、ビルド時に e-Stat の境界と照合して除外しています（記載の区から 1km 以上離れた点）。

### 合成音声の利用規約

sanoTTS-jp のモデル（つくよみちゃんコーパス由来）の条件に基づき、本ゲームが合成した音声を次の目的で使うことを禁止します。

- 人を批判・攻撃すること。（「批判・攻撃」の定義は、つくよみちゃんキャラクターライセンスに準じます）
- 特定の政治的立場・宗教・思想への賛同または反対を呼びかけること。
- 刺激の強い表現をゾーニングなしで公開すること。
- 他者に対して二次利用（素材としての利用）を許可する形で公開すること。

本ゲームには、音声を保存・書き出しする機能はありません。

### 通信とプライバシー

プレイ中、ブラウザから国土地理院・PLATEAU 配信サービス・気象庁・公共交通オープンデータセンターへ直接通信します。そのため IP アドレスなどが各サービスに送られます。発見の進捗はこのブラウザの localStorage にのみ保存します。

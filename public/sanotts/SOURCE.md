https://github.com/Ampixa/sanoTTS/archive/3de9f37cbfedb8a1edcc28f4c8139979c6fcf889.tar.gz

Build instructions are in mcu/ports/wasm/README.md; build_g2p.sh and build_voices.sh generate snt_g2p and snt_voice respectively with Emscripten.
The Chinese front end is in web/g2p-lazy/zh/; its dictionaries are generated by tools/build_zh_g2p_web_assets.py.

Local changes from that source:

- Append `export default SaanoVoice;` and `export default SaanoG2P;` to the respective JS loaders and serve as .mjs.
- At the start of `async function inflate(bytes)` in zh_g2p.mjs, return bytes unchanged when gzip magic 1f 8b is absent. HTTP Content-Encoding may have already decompressed the response.
- No model weights or dictionary entries were changed.

The local adapter and retrieval recipe are available at https://github.com/kexi/tokyo-od-game (scripts/fetch-sanotts.ts, assets/sanotts-files.json).
The retrieval script checks the SHA-256 of the unmodified source download and the resulting local file before writing.

# 法令厳守 TOKYO OPEN DRIVE

[日本語](README.md) | [English](README.en.md) | **中文**

用东京都开放数据 × PLATEAU 3D 城市模型，驾车在东京 23 区四处探索的 three.js 3D 驾驶游戏。（中文名为“严守法令 TOKYO OPEN DRIVE”。）

**游玩：** https://kexi.github.io/tokyo-od-game/

- 建筑物使用国土交通省 PLATEAU 的 3D 城市模型（建筑物 LOD1，23 区的全部建筑），从行驶地点周边直接流式加载到浏览器。
- 人行道取自 PLATEAU 道路模型 LOD2 的人行道部分，绘制为带路缘石的铺装（LOD2 覆盖千代田、中央、台东、港四区的大部分以及其他区的一部分）。行人在人行道上行走，在人行横道等信号灯后过马路。在没有人行道的窄路上，行人沿道路右侧边缘行走（道路交通法（日本《道路交通法》）第10条）。
- 地形由国土地理院的高程瓦片（DEM5A/DEM10B）生成，并用 Rapier 物理引擎处理车辆、建筑与地面之间的碰撞。
- 光柱是东京都及各区开放数据中的真实地点（文化遗产、名胜、夜景地点、都立设施、饮水点、灾害时供水点、避难场所、都营交通车站等）。
- 都营巴士依据实时位置（公共交通开放数据中心）行驶，天气反映气象厅 AMeDAS（东京）的观测值。
- 时段可从“实时／早晨／白天／傍晚／夜晚”中选择（预设由当天实际的太阳高度决定）。
- 道路依据国土地理院矢量瓦片（提供实验）的中心线与宽度绘制路面；车道线与道路标线依据「道路標識、区画線及び道路標示に関する命令」（《关于道路标志、车道线及道路标线的命令》）和 JARTIC 的交通管制信息（警视厅）绘制（禁止越线的黄色中心线、车道以及禁止变道的黄色车道分界线、黄色的最高限速数字、人行横道及其 ◇ 预告标记、停止线）。道路标志（最高速度、单行道、禁止车辆驶入、禁止停车、禁止停车及临时停车、禁止掉头、减速慢行、停车让行、禁止驶出指定方向、人行横道）立在 JARTIC 的管制路段与地点上。信号灯的位置取自 OpenStreetMap，灯头（机动车用、行人用）和信号灯杆用 Blender CLI 建模（`scripts/blender/signals.py`）。行人信号灯只在过街方向的机动车信号灯为绿灯期间为绿灯，最后 5 秒闪烁。标志立柱和信号灯杆有碰撞判定。出租车、普通车辆和路边停放的车辆靠左行驶，并在红灯和“止まれ”（停车）标志前停车。都营巴士沿道路左侧车道行驶。
- 依照《道路交通法》判定违章。对象包括闯红灯、未在停车让行处停车、单行道逆行与违反指定行驶方向（通行禁止違反，违反禁止通行）、违规掉头（指定横断等禁止違反）、未按规定减速慢行、违规变道、超速（按标志限速；没有限速标志的道路按 2026-09-01 修订后的法定限速）、通行区分違反（违反通行区分）、驾驶时使用手机、违法停车且驾驶人离开、违反安全驾驶义务，以及致人受伤事故的附加记分。累计 6 分暂扣驾照，15 分以上吊销驾照。每次违章都会在画面上盖一个章。管制按 JARTIC 的时段指定生效。
- 如果把车停在禁止停车或禁止停车及临时停车的地方后离开，停车监管员会前来拍照，并贴上违停确认标贴（放置車両確認標章）。回来后可以选择前往警察署到案（罚款与记分），或不到案（由车辆使用人缴纳违停罚款，不记分）。没有管制的路段不会取缔。
- 救护车是用 Blender CLI 建模的高规格救护车，车身侧面的色带、车尾以及引擎盖上镜像文字“救急”的贴花由 agy 绘制（未使用红十字等标志）。
- 撞到人后，要用手机拨打 119、110 报警。调度员由 Gemma 扮演，告知地点和情况后，救护车和警车会赶到。如果逃跑，会被警车追捕，并以肇事逃逸（未救护伤者，35 分）被捕。
- 支持東京都環境確保条例（《东京都环境确保条例》）规定的停车熄火（停车或临时停车时关闭引擎）。
- 在 Android（Chrome）上也可以横屏、全屏用触摸操作游玩。在 iOS 上无法使用对话 AI，将使用固定回复。
- 车辆用 Blender CLI 以程序方式建模（`scripts/blender/car.py` → `public/models/car.glb`）。有自车用的精细模型（约 5 万个三角形，带内饰、车门缝、后视镜和刹车卡钳）、AI 车辆用的低多边形版本（约 3 千个三角形），以及各自的出租车版本。纹理也是程序生成的（`assets/car/textures/`）。
- 在目的地任务中，导航会沿道路引导路线（“前方300米，右转。”的语音、下一个转弯处的箭头、小地图上的蓝线）。路线遵守单行道（包括按时段指定的）和禁止驶出指定方向的规定，偏离后会重新规划。
- 可以用手机上的应用呼叫自动驾驶出租车（L4 级，无驾驶人）。它会从附近的道路来接你，并依法行驶到目的地（任务的目的地、自己的车、附近的车站或地点）。车费按东京都特别区·武三地区 2026 年 4 月 20 日调整后的标准计算。乘车期间留在路上的自己的车，有可能被当作违法停车取缔。
- 按 O 键（或“自动驾驶”按钮）可以让自车进入自动驾驶。任务中驶向目的地，没有任务时在周边巡回，并遵守信号灯、停车让行、单行道、封闭道路、禁止驶出指定方向和限速行驶。操作方向盘、油门或刹车即可解除。
- 速度表的表盘上会显示当前所在道路的最高速度（标志限速、区域限速或法定限速），并以红色标出超过它的范围。
- 出发地点除东京站外，还可以从都营交通的各车站或浏览器的位置信息（仅限 23 区内）中选择。
- 建筑外墙按高度从 8 种（玻璃办公楼、贴瓷砖、公寓、杂居楼、仓库、砖墙等）中选择，夜晚窗户会亮灯。行人和道路标志也用 Blender 建模。
- 可以下车步行。与行人搭话，他们会告诉你附近真实地点的方向和距离。对话 AI（Gemma 4，在本机运行）和语音（sanoTTS-jp）可以按需启用。

## 开发

开发环境的搭建方法和工作流程见 [CONTRIBUTING.zh.md](CONTRIBUTING.zh.md)。`nix develop`（direnv）会备齐 Node.js 24、pnpm、just、lefthook、uv 等工具。

```sh
just install-deps          # 安装依赖（设置为不安装发布未满 1 天的软件包）
just serve-dev             # 开发服务器
just check-all             # 检查类型、lint、格式、测试、justfile 和 Actions
just fetch-data            # 获取开放数据并重新生成 public/data（带许可检查）
just fetch-regs            # 由 JARTIC 交通管制信息和 OSM 信号灯重新生成 public/data/regs、signals
just make-car-textures     # 重新生成车辆纹理（uv）
just make-car-model        # 用 Blender CLI 重新生成车辆模型（nix develop .#blender）
just make-sign-model       # 重新生成道路标志的牌面与立柱
just make-human-model      # 重新生成行人
just make-signal-model     # 重新生成信号灯（灯头、信号灯杆）
just make-ambulance-model  # 重新生成救护车
just make-textures         # 重新生成标志、行人、建筑外墙、信号灯、救护车的纹理（uv）
just open-assets           # 打开资产管理画面（预览与审阅模型和纹理）
just build-app             # 生产构建到 dist/
```

push 到 `main` 后，GitHub Actions 会部署到 GitHub Pages。

### 资产管理与审阅

资产在台账 `assets/manifest.yml` 中逐条管理名称、用途、生成脚本与 just 配方、来源和许可。如果 `assets/` 和 `public/`（`public/data` 除外）中有台账里没有的文件，`just check-assets`（也包含在 `just run-tests` 中）会失败，所以添加资产时请同时添加到台账。

用 `just open-assets` 打开的资产管理画面（`assets.html`）按种类列出台账中的全部资产。模型可以旋转查看，并有各部件的显示切换、三角形数和线框显示。纹理可以在棋盘格上查看透明效果。

给每个资产标上 OK／要修正（需修改），写下指示，放置图钉（纹理用点击，模型用 Shift+点击放在部件上），然后按「レビューを Claude に送る」（把审阅发送给 Claude），开发服务器就会写出到 `.review/pending/`。Claude Code 的钩子（`.claude/hooks/asset-review-watch.sh`，`asyncRewake`）会唤醒会话，按照 `asset-review` 技能（`.agents/skills/asset-review/`）的步骤修改生成脚本并重新生成。处理结果会显示在画面上。

### 结构

| 路径                                         | 作用                                                                                                          |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `src/geo/`                                   | WGS84、ECEF、ENU 之间的转换，浮动原点（LocalFrame），瓦片坐标，太阳位置                                       |
| `src/world/`                                 | 地形（DEM→网格＋trimesh 碰撞体）、PLATEAU 建筑（3d-tiles-renderer＋碰撞体＋窗户着色器）、天空与天气、都营巴士 |
| `src/physics/`                               | Rapier 的射线检测车辆                                                                                         |
| `src/game/`                                  | 车辆模型、相机、输入、POI、任务、小地图、声音、来源显示                                                       |
| `scripts/fetch-data.ts`                      | 构建时的数据生成。通过东京都目录的 CKAN API 查询许可，不是 CC BY 4.0 就停止                                   |
| `scripts/blender/car.py`                     | 用 Blender CLI（bpy）以放样＋细分＋布尔运算制作车身，用射线检测让灯具和车牌贴合车身，并导出为 glb             |
| `scripts/blender/signs.py`, `human.py`       | 道路标志的牌面（圆形、倒三角形、正方形、长方形）、立柱与安装件，以及行人（各部件以关节为原点导出）            |
| `scripts/blender/signals.py`, `ambulance.py` | 信号灯（机动车用与行人用灯头、信号灯杆）和高规格救护车                                                        |
| `scripts/textures/*.py`                      | 车辆、标志、行人、建筑外墙纹理的程序生成（Pillow，固定种子。委托 agy 制作）                                   |
| `scripts/regulations.ts`                     | 将 JARTIC 交通管制信息（Shift_JIS，约 400MB 的 CSV）和 OSM 的信号灯分割为 z14 瓦片并写出到 `public/data/`     |

23 区从一端到另一端约 30km，由于地球曲率，两端会下沉约 18m。因此游戏使用以车辆附近为原点的局部坐标，每离开 1.5km 就经由 ECEF 重新设置原点。

### 确认使用条件后做出的决定

- 不分发源自国土地理院大地水准面模型的数值。因为这可能需要依据測量法（《测量法》）取得批准，所以使用公有领域的 EGM2008。
- 把“地理院 标准地图”（地理院 標準地図）贴到 3D 地形上的用法，处于可能需要申请批准的边界，因此不使用。只使用航拍照片或 PLATEAU 正射影像。
- 显示地理院瓦片期间，画面下方始终显示其来源。
- 当前位置所在的区和町丁用 e-Stat 的边界多边形判定，不调用国土地理院的逆地理编码服务。气象厅的 JSON 限制为每 10 分钟最多获取 1 次。
- 源数据中的坐标错误，在构建时与 e-Stat 的边界对照后予以排除（距所记载的区 1km 以上的点）。

### 合成语音的使用条款

依据 sanoTTS-jp 模型（源自“月读酱”语料库）的条件，禁止将本游戏合成的语音用于以下目的。

- 批评、攻击他人。（“批评、攻击”的定义依照月读酱角色许可。）
- 号召支持或反对特定的政治立场、宗教或思想。
- 在未分区的情况下公开刺激性强的内容。
- 以允许他人二次利用（作为素材使用）的形式公开。

本游戏没有保存或导出语音的功能。

### 网络通信与隐私

游戏过程中，浏览器会直接与国土地理院、PLATEAU 分发服务、气象厅和公共交通开放数据中心通信。因此 IP 地址等会发送给各服务。发现的进度只保存在本浏览器的 localStorage 中。

### 探り（`scripts/expresswayEndWalls.ts`、`just check-expressway-end-walls`、合否つき）

- **線（追記 4 D6 で変えた）**: 先へ続く別の run の車道に、壁の箱が立つ点 0。前の線（別の run の車道に立つ点 0）は、互いの所で終わる端（2 本の車道が平面で重なり、両方の壁が立つ）で規則をどう直しても 0 にならない。先の無い端の路面には通り抜ける車が無い。前の線の数は `pokingRaw`（生の (b)）、高さ ± `MERGE_MAX_DZ` で読む見方は `pokingLevel`（(c)）として要約に残し、数えない壁は `uncounted`（相手の run・same か・相手の先の無い端までの距離）で 1 つずつ出す。
- 相手の車道の読み方: same の相手は、相手の床版を組んだ結果の路面の届く所（輪ごとの `sides` の reach、壁高欄・分離壁の内の面まで、(b)）。ほかは測点の中心線から車道の半幅（追記 2 B3）。
- 光線は路面 − `SLAB` まで伸ばす。− `MERGE_MAX_DZ` より下で当たった点は `deep` に別に並べ、線に入れない。
- **開きの検査（追記 5 E2）**: 光線を、箱のある幅だけでなく、端の面の全部の幅（箱の間の隙間も）に出す。面の先に路面がある光線は、その路面を車 1 台の長さまで追い（この路面 + 0.5 m の水平の光線で、立っている物までの距離を取り、0.25 m おきの下向きの光線で路面が 0.3 m 以内で続くか）、切れる所に何も立っていなければ miss。先に路面の無い隙間は `openM` で、`PARAPET_WIDTH` を超えれば miss。最初の検査は箱のある幅にしか光線を出さず、譲った刻みを見ていなかった（110def4 の 45392984:2 end の 0.8 m と 806097479:0 end の 2.15 m の開きが miss 0）。直した検査を 110def4 に掛けると、その 2 つだけを miss と出した（12 と 36）。

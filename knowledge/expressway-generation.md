# 縦断線形の解き方

1 本の run の縦断を、間隔 h（h ≥ 第22条の最小縦断曲線長）の節点で勾配が線形に変わる「等長の放物線区間の列」にした。各区間は PVI を中点に置いた長さ h の縦断曲線になる。こうすると

- 勾配の最大は節点の値の最大（第20条を節点だけで守れば全域で守れる）、
- 曲率は区間内一定（第22条第2項は節点の差の一次式）、
- 曲線長は常に h 以上（第22条第3項は勾配差が小さくても満たす）。

全部が節点の標高・勾配の一次式になるので、5 m ごとの測点の上下限（交差の桁下、地表）と端の等式（地表への擦り付け、親の z・勾配）を足しても凸 QP で、目標高（標準桁下高）に近く滑らかな縦断を解ける。解けたかどうかは余裕なしの元の制約で判定する（QP は ADMM の密な小問題で、0.5〜1 % の余裕の内側を狙う）。[^code]

解けないときは設計書 4.3 の 3 の順に、第20条の特例値 → V を下げる（本線は 40、ランプは 20 まで）→ 地表の一律の桁下を外して交差の桁下だけにする → 診断を出して失敗、と試し、試した全部を診断に残す。[^tests]

## 順序と、レイヤを目標高に使う逸脱

- ランプは合流・分岐する本線の後に解き、端の z・勾配・片勾配を本線の値に固定する（T3）。
- 交差する高架どうしは下を先に解き、上は下の路面 + 4.5 + 桁高を下限にする。分合流で循環するとき（芝公園入口は外回りの下をくぐって内回りへ合流する）は、親の済んだ run のうち「まだ下に解いていない本線」が少ないものを先に取り、交差は後に解く側が上限（下の run）か下限（上の run）として受け取る。
- **逸脱**: 設計書は「layer は上下の順序づけだけ、目標高は標準桁下高」とした。浜崎橋JCT では 1 号羽田線（下り）が C1 内回りから分かれて 100 m で外回りを越える。両方を標準高に置くと、分かれた直後に 1 段（6.7 m）上れず解けなかった。そこで **目標高（目的関数）にだけ** OSM layer − 1 段分を足した（±60 m の移動平均）。制約は交差からしか来ないままで、タグの切り替わりで段差は生じない（T2・T3 が保証）。代わりに路面は地表から高くなった（中央値／最大: C1 内回り 16.5 / 24.5 m、外回り 15.4 / 22.5 m、羽田線へ分かれる 4848762 は 27.8 / 30.2 m）。芝公園出口は V20 の特例勾配（第25条で 11.5 % に頭打ち）で降りる。恒久対応は下の「未解決の課題」。

## 地上の道路・鉄道との交差

OSM の地上の道路（trunk〜service、bridge / tunnel / layer なし）と鉄道を z16 のセルで集め、高架の下を通るものは桁下 4.5 m（鉄道は仮定の 6.0 m）+ 桁高を下限にする。ただし地表の端の近くで、標準勾配の放物線でも越えられない位置にある「地上の道路」は、掘割の上を渡る道路や立体交差の地下道（OSM で高さが分からない）と見て下限にせず、`crossing_over_or_at_grade` として診断に残す（試験区間の依存を含め 11 件、うち 5 件は C1 外回りの霞が関側の端）。端から離れた所は交差に関係なく「地表 + 4.5 + 桁高」を一律の下限にしたので、水面（DEM は岸の高さか 0）も含めて桁下は守られる（T4）。

# 未解決の課題（P2・P3 の前提、2026-11-10 レビュー）

- **設計速度は run 単位**: 1 か所の急曲線で run 全体の V が下がる。節点ごと（区間ごと）に持たせる。
- **測点の間は線形補間**: 縦断の放物線は測点間で弦になる（最大 0.1 m 程度）。測点に勾配を持たせてエルミート補間にする。
- **橋脚の回避は地上道路の交差だけ**: 下層のデッキ・並走する地上道路・水面の上に脚が立ち得る。
- **トンネル・掘割の区別**: 構造の切り替わりはすべて「地表に擦り付け」として扱っている。掘割への切り替わりと地表への擦り付けを分ける（P9）。
- **レイヤを目標高に使う逸脱の恒久対応**: 子（分かれたランプ）の交差の要求を親へ逆伝播するか、連結した run を一括の QP で解く。レビューの見通しでは、平坦地の全域で 763 run 中 165 が今の方式では解けない。
- **地表近くの床版が道路を塞ぐ箇所**: `crossing_over_or_at_grade` で拘束にしなかった道路を、タイルに記録して P3 で扱う。
- **データ量**: 全域のチャンクは 2.96 MB の見込みで、目安 1 MB の 3 倍を超える（測点の間隔・丸めの見直し）。
- **ランプの半径**: 全域では ramp_radius が 6 件（R 10.7〜14.5 m、下限 15 m 未満）。試験区間の出力には無い（203873831 は今の依存関係では解く対象に入らず、診断も出ない）。
- **性能**: 静かな機械で 5 回以上測り直す（今回は負荷平均 8〜30 で 2 回ずつ）。
- **地表の標高の同梱**: 測点と橋脚に地表の標高（標高タイルを平滑化した値）を同梱し、桁と橋脚を地面で止めるのに使っている。LICENSE.txt と出典画面に明記した。

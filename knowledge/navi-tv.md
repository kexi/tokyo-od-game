# 法令

| 条文                 | 内容（e-Gov の現行版）                                                                                                                                                                                                                                           | ゲームでの扱い                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 第71条第5号の5       | 自動車等（現行版は自転車を含む）を運転するときは、**停止しているときを除き**、手で保持しなければ送受信できない無線通話装置を通話に使わず、また「当該自動車等に**取り付けられ若しくは持ち込まれた**画像表示用装置」に表示された画像を**注視しない**こと[^egov-71] | ナビの映像は停車中だけ。スマホの保持は従来どおり `携帯電話使用等（保持）` |
| 同号の除外           | 道路運送車両法 第41条第1項第16号（後写鏡・窓拭き器その他の視野を確保する装置）・第17号（速度計等の計器）、第44条第11号（原付の速度計）[^egov-sharyo]                                                                                                             | ナビのテレビは除外に当たらない                                            |
| 第118条第1項第4号    | 6 月以下の拘禁刑又は 10 万円以下の罰金。対象は、無線通話装置を通話に使った者と、**持ち込まれた**画像表示用装置を**手で保持して**画像を注視した者[^egov-penalty]                                                                                                  | 保持（3 点・普通車 18,000 円）。取り付けたナビの注視はこの号に当たらない  |
| 第117条の4第1項第2号 | 第71条第5号の5 に違反し、よって道路における交通の危険を生じさせた者。1 年以下の拘禁刑又は 30 万円以下の罰金[^egov-penalty]                                                                                                                                       | `携帯電話使用等（交通の危険）`（6 点、反則金なし）。スマホを操作中の事故  |

- 第71条の罰則の注記は「第五号の五については第百十七条の四第一項第二号、第百十八条第一項第四号」だけ。条文から読む限り、**取り付けたナビの画像を注視しただけ**（危険を生じさせていない）は、遵守事項の違反ではあるが、この 2 つの罰則のどちらにも当たらない。警察の運用・判例は確かめていない。
- 点数と反則金は警察庁のページの表と一致（交通の危険: 基礎点数 6 点・反則金の適用なし、保持: 3 点・普通車 1 万 8 千円）。[^npa-keitai]

## 「注視」の目安（2 秒）

- 法令に秒数の定義は無い。
- 警察庁のページは「運転者が画像を見ることにより危険を感じる時間は運転環境により異なりますが、各種の研究報告によれば、**２秒以上見ると運転者が危険を感じる**という点では一致しています」と書き、時速 60 キロで 2 秒間に約 33.3 m 進むと示す。[^npa-keitai]
- 依頼文の「警察庁の解釈で約 2 秒」は、正確には**危険を感じる時間についての研究の一致**の紹介で、注視の法的な定義ではない。ゲームはこれを目安に、スマホを「直近 2 秒以内に触った」ときを使用中としている（phone.ts の isInUse）。
- 同じページが引く交通の方法に関する教則は、自動運行装置を適切に使っている場合を除き、走行中に「カーナビゲーション装置などに表示された画像を注視したりしてはいけません」とする。[^npa-keitai]

# ゲームでの振る舞い

`src/game/tvRules.ts`（規則・番組・テロップ・音の波形、DOM なし）と `src/game/naviTv.ts`（描画・音・状態）。ナビの地図と同じ canvas（`CarNavi.canvas`、640×400）に描く。

| 状況                                                                                                                 | 画面                                                              | 音               |
| -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ---------------- |
| 速さ 1 km/h 未満、かつパーキングブレーキ（Space、簡単操作のブレーキ保持）かエンジン停止（E、アイドリング・ストップ） | 番組                                                              | 番組             |
| それ以外（走行中、ブレーキペダルだけで停止中）                                                                       | 「走行中は映像を表示できません」「10ch げんしゅテレビ　音声のみ」 | 番組（音声のみ） |
| 走行中に テレビ を押した                                                                                             | 同じメッセージ（映像は出ない）                                    | 番組             |
| 簡単操作・ルート案内中に走り出した（1 km/h 未満から 3 km/h 以上）                                                    | 地図に戻る。時計の下に「♪ 10ch」                                  | 続く             |
| 降車                                                                                                                 | 消える（キーを抜いた扱い。チャンネルは覚えている）                | 消える           |

- 操作: テレビ = `3`、チャンネル = `4`（両レイアウト共通、F キーの代わりに使っていない数字）。ツールバーに「テレビ」「チャンネル」（広い画面のみ）、操作説明に 1 行。テレビは「地図 → テレビ（点く）→ 消す」、地図の裏で音が鳴っているときは「テレビの画面に戻す」。チャンネルは 10 → 11 → 12 → 10、消えているときは前のチャンネルで点く。
- 判定の入力は main.ts から毎フレーム渡す: 速さ `vehicle.speedKmh()`、パーキングブレーキ `drive.handbrake`、エンジン停止 `isEngineOff || !controls.engineOn`。後退も「走り出した」に数える（ヘッドレスで確認）。
- **簡単操作のブレーキ保持をパーキングブレーキとみなすのは単純化**。実車の電動パーキングブレーキのオートホールドとパーキングブレーキ信号は別物で、ナビによっては保持中に映像を出さない。リアル操作では Space を押している間かエンジンを止めている間だけ映る（Space はラッチしない）。

## 走行中の切り替えを違反にしない理由

1. 第71条第5号の5 が禁じるのは、手で保持する無線通話装置での通話と、画像の**注視**。取り付けたナビのボタンを押すのは保持ではない。[^egov-71]
2. 走行中は映像を出さないので、注視する画像が無い（走行中のテレビの注視は起こりえない）。
3. ボタン 1 回は、警察庁の示す 2 秒にも、自工会の操作基準（合計 8 秒）にも遠く及ばない。[^npa-keitai] [^jama-v30]
4. 操作に気を取られて事故を起こせば、事故ごとの安全運転義務違反（第70条）が既に記録される。

代わりに、走行中に初めて操作したときだけ「走行中の操作は手短に」と添える。対比として、スマホは画面を見る・手で持つものなので、5 km/h を超えて直近 2 秒に操作していれば `携帯電話使用等（保持）`、その間の事故は `交通の危険` にしている（main.ts）。

# 番組（架空）

実在の放送局の名前・ロゴ・番組名・キャラクター・出演者は使わない。局名は法令厳守にちなむ「げんしゅ」。チャンネル番号は東京の地上波で知られた 1〜9 を避けて 10〜12。テストで実在局名が入っていないことを確かめている。[^unit]

| ch  | 局名           | 番組                                                                                                                                   |
| --- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 10  | げんしゅテレビ | 「げんしゅニュース」: スタジオ（窓の外の街、机、顔のない読み手の図形、横のモニタに項目の絵）、ロワーサード、下のテロップ               |
| 11  | げんしゅ天気   | 「いまの23区」: e-Stat 町丁境界（3,149 町丁）から描いた 23 区の地図、いる区を黄色、現在地の赤丸、空の記号、気温・湿度・風・10 分間の雨 |
| 12  | げんしゅ自然   | 「げんしゅ自然紀行」: 山・森・川・鳥（夜は月）。1:00〜5:00 は放送休止のカラーバー（75% バー・リバース・−I／白／+Q・PLUGE）と 1 kHz     |

- ニュースの項目（12 秒ごとに次）: 時刻 / 現在地（区・町丁）/ 天気 / 本日の交通違反（その日の記録を種類ごとに 1 回、括弧の詳細は外し、うち検挙の件数。0 件なら「きょうも法令厳守です」）/ 交通安全（「走行中に画面を注視するのは道路交通法違反です（第71条）」）。
- 天気の数値は北の丸公園の観測（ゲームが取得済みのアメダス 10 分値）。空模様は、実況のときだけ観測（雨・日照時間で晴れ／くもり、夜は「雨なし」）、晴れ／雨／おまかせのときはゲームの天気で、「（ゲームの天気）」と添える。予報は出さない（データを持っていない。「この先の天気は「天気」ボタンしだいです」）。
- 受信料のお知らせ（フィクション）: このブラウザで初めて映像が映ったときに 12 秒、画面の中央に出す。チャンネルで閉じる。「げんしゅ放送の受信料は「法令厳守」です。本日の交通違反 n 件 × 0 円 ＝ 0 円」。組織名・様式・支払先・番号・期日は無く、請求書に見えるものは置かない。ゲームの操作は止めない。

# 音

- 番組ごとのループ（tvRules.ts の `programmeBed`）: ニュースは A の和音（0.25 Hz 刻みで 4 秒に整数周期）、天気は 8 音の五音音階のアルペジオ、自然は一次低域通過の雑音を 2 周回して継ぎ目を消したせせらぎと鳥 3 声、カラーバーは 1 kHz。ループの継ぎ目の段差がループ内の最大の段差を超えないことをテストした。[^unit]
- 鳴らす位置: `SpatialAudio.cabinSpeaker`。ナビ画面（`Display_Center` の境界箱の中心、車の座標系）に置いた PannerNode を **interior バス**に入れる。車内の残響は付くが外の音のような遮音は通らず、追従視点や降車では interior バスが 0 になって聞こえない（ヘッドレスで interior 1 → 0 を確認）。パンは equal-power（60 cm 正面では HRTF の利点が小さく、12 の定位枠を 1 つ使わないため）。[^browser]
- 音量: ループ 0.02〜0.09、読み上げ 0.45（耳から 0.4〜0.8 m）。ミュートと 音量 は master で効く。
- 読み上げ: 端末内音声（sanoTTS-jp）が有効なら `Voice.speak` の VoiceFrom で TV の読み上げ用ゲインへ。無効なら speechSynthesis（音量 = 音量×0.6、運転席視点のときだけ。WebAudio に通せないため）。ミュート中は読まない（合成が人のセリフの前に溜まるため）。会話中・通話中・パトカーの追尾／取り締まり中は待つ。ヘッドレスで、端末内音声の経路で「21時30分になりました。」「現在地は、千代田区丸の内二丁目付近です。」「天気は雨です。都心の気温は18度、湿度は75パーセントです。」「本日の交通違反は、ゼロ件です。法令厳守、お見事です。」が順に渡るのを確かめた。[^browser]

# 落とし穴

1. **視点の初期値は運転席になっていた**。検証で C を 3 回押したらボンネット視点になり、ナビが映らなかった（camera.ts の `mode: "cockpit"`）。
2. **天気を「実況」だけ観測とみなすと、おまかせ（2026-10-05 に別の変更で追加、既定）では気温も消えた**。空模様（ゲームの設定）と数値（常に観測）を分けた（`fixedSky`）。
3. **地図の下の帯に置いた「♪ 10ch」が見えなかった**。2026-10-05 03:59 の cockpit.glb（運転姿勢の作り直しの途中）では、画面の下 15% ほどがダッシュボードの上面に隠れる（ナビの現在地・制限速度の帯と、ニュースのテロップも隠れる）。印は時計の下に移した。隠れる件は車内モデル側の問題として報告した。[^browser]
4. **読み上げの間隔は実時間**。ヘッドレスで `advance(16)`（ゲーム 16 秒）の間に 8 項目読まれたのは、高負荷で 1 フレームが実時間で長く、dt が 0.05 秒で頭打ちになりゲーム時間が遅れたため。間隔の不具合ではない。
5. 音声の待ち行列は人のセリフと共有なので、テレビは人が話している間は読まず、ミュート中は合成もしない。

# 制限

- 視線は追っていない。走行中にナビの**地図**を 2 秒以上見る注視は判定しない（テレビの映像は走行中に出ないので注視しようがない）。
- 予報は無い。観測は 1 地点（北の丸公園）。
- 一時停止中・リプレイ中もテレビの音は鳴り続ける（本物のテレビと同じ扱い）。
- パーキングブレーキ信号線の仕組みは未確認（上記）。

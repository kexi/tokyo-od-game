# 何が起きていたか

- 公共施設一覧の「東京臨海広域防災公園」（江東区有明）が、東京駅前（35.6804, 139.769017）に置かれていた。ゲームでは丸の内の歩行者が「もいいですね」と案内してしまい、それで気づいた。
- 反証検証では、公共施設一覧に座標の誤りが 6 件（緯度と経度の入れ違い、住所の誤記）見つかった。文化財一覧にも、数値として読めない経度が 1 件あった。[^verify-batch]

# 検証ルール

1. e-Stat の小地域境界（23 区の陸域 3,149 町丁）を約 5m で単純化し、`public/data/areas.json` に同梱する（gzip 後 530KB）。[^estat-boundary]
2. POI の座標を判定した区が、記録にある区と異なる場合は、半径 300m と 1000m の円周上を 16 方向ずつ調べ、記録の区が 1 点でもあれば残す。
3. どこにも記録の区が無ければ除外する。

# 効かなかったこと

**単純な「区が一致しなければ除外」** は過剰に除外した。予想は誤りデータ数件の除外だったが、実際には 23 件が落ちた。区境にある駅（新宿駅・飯田橋駅・国立競技場駅）や、複数区にまたがる広域避難場所（「〜一帯」）が正しい座標のまま落ちていた。1km の許容を入れて、除外は 5 件になった。[^build-log]

| 除外された点                 | 記録の区 | 座標の区              |
| ---------------------------- | -------- | --------------------- |
| 東京臨海広域防災公園         | 江東区   | 中央区（約 5km ずれ） |
| 大井ふ頭一帯                 | 品川区   | 大田区                |
| 多摩川河川敷・田園調布先一帯 | 大田区   | 世田谷区              |
| 浮間公園・荒川河川敷緑地一帯 | 北区     | 板橋区                |
| 新河岸東公園一帯             | 北区     | 板橋区                |

下 4 件は広域避難場所の代表点が区外にあるケースで、誤りとは限らない。

# 副産物

同じ境界データを実行時の現在地表示（区・町丁）にも使い、国土地理院の逆ジオコーダへの問い合わせを無くした（[利用条件](licensing-decisions.md)）。町丁の人口密度（2020 年国勢調査）は、歩行者の人数の調整に使っている。

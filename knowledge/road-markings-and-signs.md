# 色と設置条件（命令、e-Gov の現行版で確認）

区画線の寸法は国土交通省の標準による。中央線の破線は都市部で長さ 5m・間隔 5m、線幅は 0.10〜0.20m。[^mlit-lines] 標識の形は道路標識一覧で確かめた。~~一方通行は、通りを走る車から見るので矢印が上を向く縦型（326-B）を使う。~~ **訂正（2026-10-04）**: 道路標識設置基準 3-1-4 では、路側式の規制標識は車の進行方向に対して直角または斜め（45〜90°）に取り付ける。ただし一方通行（326-A）だけは平行または斜め（0〜45°）とされている。[^setti] 横型の 326-A（60 × 35cm）を道路と平行に付け、両面に表示する。車道側の面は右向きの矢印、裏面は左向きで、どちらから見ても許された向きを指す。縦型にしたのは、他の標識と同じく正面から見せるものと思い込んだため。[^mlit-signs]

# JARTIC のコードの読み方

| コード          | 内容                                       | 読み方                                                                                                                                                                              |
| --------------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 115・65・51・61 | 駐車禁止・駐停車禁止・転回禁止・徐行（線） | 「片側・両側コード」が 2 なら座標順の片側だけ、それ以外は両方向に標識を立てる                                                                                                       |
| 17              | はみ出し禁止（線）                         | 1,551 行すべて両側（3）                                                                                                                                                             |
| 20              | 車両通行帯（線）                           | 「車両通行帯数」は 5,260 行中 761 行だけに入っている。空なら片側の幅員から 2〜4 車線と推定する。1 方向に 3m 以上で収まらない本数なら両方向の合計とみなす                            |
| 12              | 指定方向外進行禁止（点）                   | 点は交差点の中央。「進入方向（座標）」が流入路、「指定する方向（座標）」が許される流出路（仕様書 K 2.1 の点規制 (2)）。流入の向きに対する角度で左・直進・右に分け、標識の矢印にする |
| 63              | 一時停止（点）                             | 「進入方向（座標）」は 141,176 行中 74 行だけ。方向は停止線の左右（左側通行）から推定するまま                                                                                       |

[^jartic-spec]

標識は、規制区間の始点から 3m の位置と一定間隔（最高速度 300m、駐車禁止 200m、一方通行 150m）で設置点を作る（2026-10-04 からビルド時ではなく実行時に区間から作る）。実行時に道路区間へ寄せ、その方向の車から見て左側の路端に立てる。一方通行の区間では「車両進入禁止」だけが逆走側を向く。区域規制（ゾーン 30）の標識は、区域の外の道路から区域に入る区間の入口に立てる。

丸の内（スポーン地点）周辺では、標識 645 本・横断歩道 297 か所になった。[^game-run]

# 落とし穴

1. **広い道路で線が路面に埋もれていた**。路面の帯を幅方向の両端 2 点だけで張っていたので、幅 32.5m の道路では中央付近の路面が地形より数十 cm 浮いていた。線は地形の高さ＋1.5cm に描くため、路面の下に隠れた。地面の写真が路面から透けて見える現象も同じ原因だった。路面を幅方向にも 2.5m 間隔で分割して解消した。
2. **標識の三角が上下逆になった**。glTF の UV は v が画像の下向きに進む。GLTFLoader は自前のテクスチャに `flipY = false` を設定するが、`TextureLoader` で別に読んだ画像は既定で `flipY = true` なので、glTF のメッシュに貼ると上下が逆になる。最高速度の「30」は上下対称なので気づけず、「止まれ」が菱形に欠けたことで分かった。
3. **標識が交差点の中や横断歩道の上に立っていた**。規制区間は交差点の中心から始まることが多く、「始点から 3m」の位置は幅 25〜40m の交差道路の車道の中だった。丸の内周辺の 656 本のうち 70 本が他の道路の車道の中にあった。設置点を進行方向へ 3m ずつ（最大 45m）ずらし、他の道路の車道（半幅＋0.5m）にも横断歩道（±3.5m）にも掛からない最初の位置に立てる。見つからなければ立てない。建物の中に入るもの（GSI の幅員が歩道込みで実際の車道より広い区間）は、建物タイルが読み込まれた後に隠す。調整後は 557 本で、車道の中は 0 本になった。
4. **大きな交差点の中に車線が引かれていた**。地理院の中心線では、大きな交差点は複数の節点と短い区間でできている。3 叉以上の節点だけで区画線を止めると、交差点の中の短い区間に中央線・車線境界線が残った。中心線の点が、向きの 32° 以上違う他の道路の車道の中にある間は線を引かないようにした。
5. **横断歩道が道路とずれていた**。JARTIC の横断歩道の両端は地理院の中心線と別に計測されている。そのため、道路に沿った位置だけを使い、縞は道路の向きと車道の幅に合わせて描く。道路と平行な横断歩道は交差する側の道路のものなので捨てる。

# 結論

**Y に都の報道発表を流す機能は作らない（2026-10-05）。** RSS のページが「本サイトで公開するRSSを利用した「新着情報」の再配布、メールマガジンの作成、サイトの構築などをされる場合は必ず事前に申請をお願いします。審査の結果、お断りする場合があります。」と定めている。[^rss-policy] 公開するゲームの画面に見出しを出すのは「再配布」「サイトの構築」に当たる。申請せずに作ることはしない。

サイト全体の著作権の扱いも CC BY ではない。「「私的使用のための複製」や「引用」など著作権法上認められた場合を除き、無断で複製・転用することはできません。」と書かれている。[^chosakuken] RSS の `<copyright>` も `Copyright (C) 2021~ Tokyo Metropolitan Government. All Rights Reserved.` である。[^feed] Gemma で要約して見せるのは複製に加えて改変にもなるので、なおさら許諾が要る。

[データ・ソフトウェアの利用条件](licensing-decisions.md) の「東京都・各区 = CC BY 4.0」は、オープンデータカタログのデータセットの話である。都庁総合ホームページの記事や RSS には当てはまらない。

# 申請が通ったときの設計（下書き）

作るのは、都の申請が通り、許された範囲（見出しだけか、リード文もか、要約という改変を認めるか）が書面でわかってからにする。そのときは次の形を想定している。

- **アカウント**: 都や実在の団体に見えない架空の集約アカウントにする。例は「都政ニュースまとめ（非公式）」。プロフィールに「東京都公式ホームページの報道発表の見出しを紹介する非公式アカウント」と書く。都の名前を表示名に入れず、ロゴ・紋章・シンボルマークは使わない。
- **出典**: ポストごとに元の題名をそのまま載せ、元のページの URL（`link`）へのリンクと「出典：東京都公式ホームページ」を付ける。表記は許諾の条件に合わせる。要約は「要約」と明記し、題名とは分けて出す。
- **取得**: CORS が無いので、ビルド時のスナップショットにする。`scripts/` の tsx で `public/data/tokyo-news.json`（`fetchedAt`・`source`・`licence`、項目は `link`・`title`・`description` を短く切ったもの・`pubDate`）に書き出す。`content:encoded` の全文は使わない。第三者の CORS プロキシは使わない。デプロイのワークフローは「ビルド時に外部 API を叩かない」方針なので、取得の手順を足すなら失敗してもコミット済みのファイルで続ける形にする。
- **時刻**: `pubDate` は日付だけ（0 時）なので、そのまま投稿時刻にすると「〇時間前」が実際とずれる。ゲームの時計で「その日の夕方の更新」として見せるか、日付だけを表示するかは、作るときに決める。
- **Gemma の要約**: `brain.status` が ready のときだけ、witnessShot が空いてから要約させる。プロンプトは与えた題名とリード文の要約だけを指示し、推測や意見を禁じる。長さに上限を設け、既存の BLOCKED の検査を通す。失敗したら題名とリード文を短く切ったものに戻す。
- **要約のキャッシュ（2026-10-05 の追加依頼）**: 1 件につき要約は 1 回だけにする。キーは項目の `link`、題名とリード文のハッシュ、プロンプトとモデルの版、表示の言語の組み合わせ。保存先はブラウザの IndexedDB か localStorage で、try/catch で包み、件数の上限を決めて古いものから消す（LRU）。ストレージが使えなければ毎回要約する。テストは、キャッシュに当たる・外れる、文やプロンプトの版が変わったら無効になる、の 3 つを確かめる。
- **引用リプと返信（2026-10-05 の追加依頼）**: ニュースのポストにも、架空のアカウントの返信と引用を付ける。social.ts の既存の返信・引用の仕組みと速さ（k 件目の時刻、直近 30 件を避ける選び方）をそのまま使う。中身は見出しの話題への一般的な反応（「これ地味に助かる」「近所でやってほしい」）に限り、題名とリード文に無い事実を作らない。都政への政治的・党派的な意見は書かず、BLOCKED の検査を通す。Gemma が ready なら題名とリード文だけから書かせて、要約と同じくキャッシュする。使えないときは、大まかな話題（催し・防災と天気・道路と交通・健康・その他）をキーワードで選んでテンプレートから書く。日本語・English・中文は Y のほかのポストと同じ扱いにする。ただし題名は訳さないので、英語・中国語の画面では題名を日本語のまま出して短い注記を添える。
- **リポスト（2026-10-05 の追加依頼「引用リツイートも」）**: コメントの付いた引用とは別に、コメントの無いリポストも付ける。social.ts の `reach` と拡散の曲線（`reposts = reach × spread`）、フォロー中の人の `reposters`（タイムラインに「〇〇さんがリポスト」）をそのまま使う。画面の文言は Y の既存のもの（リポスト）にし、「リツイート」や他社の名前・印は出さない。

# 確かめていないこと

- 「再配布」「サイトの構築」に、ゲームの中で見出しを表示することが含まれるという読みは、規約の文言からの解釈である。都に問い合わせてはいない。
- 個々の報道発表の題名が著作物に当たるか、「引用」（著作権法第32条）として出せるかは判断していない。規約が RSS の利用に事前の申請を求めているので、そちらに従った。

# 設計

| 項目           | 決めたこと                                                                                                                                                                                                                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 言語           | `ja`（日本語）・`en`（英語、米式綴り）・`zh`（簡体字中国語）。`<html lang>` は `ja` / `en` / `zh-Hans`                                                                                                                                                                                                                |
| 既定           | 保存した選択（localStorage `tod.lang`）があればそれ。無ければ `navigator.languages` を先頭から見て、主タグ（`ja-JP` → `ja`）が最初に一致した言語。どれも無ければ英語                                                                                                                                                  |
| 繁体字         | `zh-TW`・`zh-HK`・`zh-Hant` も今は `zh`（簡体字）になる。**制限**: 繁体字の辞書が無い。足すなら `zh-Hant` を別ロケールにして `detectLocale` で地域・文字体系を見る                                                                                                                                                    |
| 保存           | ピッカーで選んだときだけ保存する（同じ言語を選んでも保存する）。検出した言語は保存しないので、選ぶまではブラウザの設定に従う。ストレージが使えなくても切り替え自体は効く                                                                                                                                              |
| 引き方         | `t(key, params?)`。見つからなければ zh → en → ja → キーそのもの（en は en → ja、ja は ja → キー）。空文字も「無い」扱い。開発ビルドでは `warn("i18n_missing", { locale, key })` を 1 キー 1 回だけ出す（毎フレーム呼ぶ読み込み表示で溢れないように）                                                                  |
| 差し込み       | `{name}` を params で置き換える。無い名前は `{name}` のまま残し、画面で欠けが見えるようにする                                                                                                                                                                                                                         |
| 静的な HTML    | `data-i18n="key"`（textContent。**子要素の無い要素だけに付ける**、子要素ごと置き換わるため）、`data-i18n-title` / `data-i18n-placeholder` / `data-i18n-aria-label`（その属性）。`applyI18n(root)` が読み込み時と切り替え時に当てる                                                                                    |
| コードで組む文 | キー 1 つなら `setI18nText(el, key)`（data-i18n を付けて文字を入れる）。params や実行時に選ぶキーなら `bindText(el, () => t(...))`。関数を WeakMap に覚え、`data-i18n-bound` を付けた要素を切り替えのたびに描き直す                                                                                                   |
| 切り替え       | `setLocale()` が `<html lang>` を変え、文書全体に `applyI18n`、`onLocaleChange` の購読者を呼ぶ。再読み込みしない                                                                                                                                                                                                      |
| 中国語の字形   | `html:lang(zh) body` のフォントを PingFang SC → Hiragino Sans GB → Microsoft YaHei → Noto Sans SC の順にした。ヒラギノに無い簡体字だけが代替フォントになり、字形が混ざって読みにくくなるため。body だけを変えるので、切符・Y のように自前のフォントを持つ部分はそのまま。ロゴ（`<h1 lang="ja">`）は日本語の字形のまま |

Why not i18n ライブラリ: 要るのは引く・差し込む・切り替えで描き直すの 3 つで、百数十行で足りる。ライブラリは複数形・ICU の仕組みと独自の読み込みを持ち込む。パッケージを足さない指示もあった。[^core]

## boot.ts を main.ts より先に読む

`index.html` は `src/i18n/boot.ts` を `src/main.ts` の前に別の `<script type="module">` で読む。boot.ts は `initI18n()` と言語ピッカーの配線だけをする。

- 理由: ES モジュールの最上位のコードは、そのモジュールが import するもの全部（three.js・Rapier・世界の描画）を読み終えてから走る。main.ts の中で初期化すると、開発サーバーでは数秒、タイトル画面が日本語のまま見えてから切り替わる。boot.ts の依存は辞書と log.ts だけなので先に走る。
- 確かめていないこと: 本番ビルド（`vite build`）では HTML の module script が 1 つの入口チャンクにまとめられる可能性があり、その場合は初回の読み込み中（チャンクを取り終えるまで）日本語が見える。ビルドしての確認はしていない。気になるなら boot.ts から `import("../main")` で動的に読む形にすれば、小さな先行チャンクに分かれる。
- main.ts は `initI18n()` を呼ばない（boot が先に呼ぶ。2 回目以降は何もしない）。main.ts は `import * as i18n` で名前空間として読む。main には時刻・タクシーの `t` という局所変数があり、`t` を直接読むと oxlint の no-shadow が 4 件出たため。

# タイトル画面の言語ピッカーと 設定

- 右上に `日本語 | English | 中文`（それぞれ自分の言語で書く）の分割ボタン（`.panel.segmented`、時間帯のボタンと同じ見た目）と `⚙ 設定` を並べた（`.title-prefs`、`position: absolute`）。選んだ言語は `aria-pressed="true"`。中文 ボタンの title は「简体中文」。
- 設定 の先頭に「言語 / Language / 语言」の行（`#opt-lang`）を足した。この見出しだけは訳さない。読めない言語になっていても、自分の言語の名前で見つけられるように。
- タイトルの 設定 ボタンは `data-action="settings"` で、main.ts が全 `[data-action]` に付けるクリック処理から既存の `input.on("settings")` を通って `#settings` を開く。ダイアログの中身（画質パネル・操作設定の入力）は main() の途中で配線されるので、ボタンは `disabled` で始め、main.ts が `settingsDialog` の close 処理を付けた直後に有効にする（読み込み中は スタート と同じく待ちの見た目）。
- タイトルで開いたときは何も一時停止していないので、見出しの「一時停止中」を隠し、閉じるボタンを「閉じて再開」ではなく「閉じる」にした。CSS の `#loading:not([hidden]) ~ #settings` で切り替える（スクリプトは触らない）。`paused` は開くときに保存し閉じると戻すので、タイトルでは false → true → false になり、タイトルの描画（`state !== "playing"` の分岐が `paused` より先）にも スタート にも影響しない。

# キーの足し方

1. `src/i18n/ja.ts` に `"area.name": "日本語"` を足す。区分は `title.` `loading.` `start.` `settings.` `graphics.` `toolbar.`（ラベル）`toolbarTitle.`（ツールチップ）`ai.reason.`。
2. `en.ts` と `zh.ts` にも同じキーを足す。足さないと `Messages` 型で tsc が落ちる（余分なキーも落ちる）。`{slot}` は 3 言語で同じにする（テストが確かめる）。
3. 静的な HTML なら要素に `data-i18n="キー"` を付け、要素の中の日本語は ja.ts と同じにしておく（スクリプトが走る前に見える文。テストが空白を詰めて比べる）。文と子要素が混ざっているラベルは、文だけを `<span data-i18n>` で包む。
4. コードなら `t()`。切り替えで変わる必要がある画面の文は `setI18nText` か `bindText` にする。トーストのように数秒で消える文は `t()` だけでよい。

# 訳の方針

- 直訳しない。画面の言葉として短く書く。英語は米式綴り（color, license）、中国語は大陸の UI の慣習（全角の句読点、法令名は《》）。
- 法令名: 道路交通法 → Road Traffic Act / 《道路交通法》、東京都道路交通規則 → Tokyo Metropolitan Road Traffic Rules / 《东京都道路交通规则》。条項は `Art. 55(2)` / `第55条第2款`（項 → 款、号 → 项）。
- ロゴ「法令厳守 TOKYO OPEN DRIVE」は訳さない。副題で意味を伝える（英: "Drive Tokyo's 23 wards by the letter of the law — …"、中: 「严守交通法规，驾车畅行东京 23 区 —— …」）。
- SNS は「Y」のまま。実在のブランド名は出さない。
- 歩行者の声（sanoTTS-jp）は日本語しか話さないので、英・中では「Japanese」「日语」と書いた。
- ツールバーのボタンは 120 px（左右の余白 8 px、鍵との間 6 px、鍵 17〜28 px）で、ラベルに使えるのは約 70 px。13 px の文字で英字およそ 11 字、漢字 5 字を上限にし、テストで確かめる（"Destination" "Fast travel" "Time of day" が 11 字）。超えたら既存の `text-overflow: ellipsis` で切れる。撮影は "Screenshot"（10 字、F12 の鍵と並ぶと約 66 px で際どい）をやめて "Snapshot" にした。実際の幅はブラウザで測っていない。[^no-browser]

# 落とし穴

- `data-i18n` を子要素のある要素に付けると、子要素ごと消える。`<label>キー配置 <select>…</select></label>` のような所は文だけを `<span>` で包んだ。`.control-options label` は grid、`.check` は flex なので、包んでも並びは変わらない（テキストも span も 1 つの項目になる）。
- `:lang(zh)` を全要素に当てるとフォントが継承ではなく各要素に直接付き、切符や Y の明朝・手書きのフォントを上書きしてしまう。body だけに当てた。
- `<html lang>` を `en` にしても、フェーズ 2 までは HUD などが日本語のままなので、読み上げソフトがそこを英語の発音で読む。
- 会話 AI の同意画面（`#ai-consent`、フェーズ 2）は文が日本語のまま、使えない理由だけが選んだ言語になって混ざる。理由をキーにしたのはタイトル画面の注記を切り替えに追従させるため。
- テストは DOM を持たない（vitest の環境は node、jsdom は入れていない）。applyI18n は属性と textContent しか使わないので、偽の要素で確かめた。

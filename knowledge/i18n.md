# 設計

| 項目           | 決めたこと                                                                                                                                                                                                                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 言語           | `ja`（日本語）・`en`（英語、米式綴り）・`zh`（簡体字中国語）。`<html lang>` は `ja` / `en` / `zh-Hans`                                                                                                                                                                                                                |
| 既定           | 保存した選択（localStorage `tod.lang`）があればそれ。無ければ `navigator.languages` を先頭から見て、主タグ（`ja-JP` → `ja`）が最初に一致した言語。どれも無ければ英語                                                                                                                                                  |
| 繁体字         | `zh-TW`・`zh-HK`・`zh-Hant` も今は `zh`（簡体字）になる。**制限**: 繁体字の辞書が無い。足すなら `zh-Hant` を別ロケールにして `detectLocale` で地域・文字体系を見る                                                                                                                                                    |
| 保存           | ピッカーで選んだときだけ保存する（同じ言語を選んでも保存する）。検出した言語は保存しないので、選ぶまではブラウザの設定に従う。ストレージが使えなくても切り替え自体は効く                                                                                                                                              |
| 引き方         | `t(key, params?)`。見つからなければ zh → en → ja → キーそのもの（en は en → ja、ja は ja → キー）。空文字も「無い」扱い。開発ビルドでは `warn("i18n_missing", { locale, key })` を 1 キー 1 回だけ出す（毎フレーム呼ぶ読み込み表示で溢れないように）                                                                  |
| 差し込み       | `{name}` を params で置き換える。無い名前は `{name}` のまま残し、画面で欠けが見えるようにする                                                                                                                                                                                                                         |
| 静的な HTML    | `data-i18n="key"`（textContent。**子要素の無い要素だけに付ける**、子要素ごと置き換わるため）、`data-i18n-title` / `data-i18n-placeholder` / `data-i18n-aria-label`（その属性）。`applyI18n(root)` が読み込み時と切り替え時に当てる                                                                                    |
| コードで組む文 | キー 1 つなら `setI18nText(el, key)`（data-i18n を付けて文字を入れる）。params や実行時に選ぶキーなら `bindText(el, () => t(...))`。関数を WeakMap に覚え、`data-i18n-bound` を付けた要素を切り替えのたびに描き直す                                                                                                   |
| 切り替え       | `setLocale()` が `<html lang>` を変え、文書全体に `applyI18n`、`onLocaleChange` の購読者を呼ぶ。再読み込みしない                                                                                                                                                                                                      |
| 中国語の字形   | `html:lang(zh) body` のフォントを PingFang SC → Hiragino Sans GB → Microsoft YaHei → Noto Sans SC の順にした。ヒラギノに無い簡体字だけが代替フォントになり、字形が混ざって読みにくくなるため。body だけを変えるので、切符・Y のように自前のフォントを持つ部分はそのまま。ロゴ（`<h1 lang="ja">`）は日本語の字形のまま |

Why not i18n ライブラリ: 要るのは引く・差し込む・切り替えで描き直すの 3 つで、百数十行で足りる。ライブラリは複数形・ICU の仕組みと独自の読み込みを持ち込む。パッケージを足さない指示もあった。[^core]

## boot.ts を main.ts より先に読む

`index.html` は `src/i18n/boot.ts` を `src/main.ts` の前に別の `<script type="module">` で読む。boot.ts は `initI18n()` と言語ピッカーの配線だけをする。

- 理由: ES モジュールの最上位のコードは、そのモジュールが import するもの全部（three.js・Rapier・世界の描画）を読み終えてから走る。main.ts の中で初期化すると、開発サーバーでは数秒、タイトル画面が日本語のまま見えてから切り替わる。boot.ts の依存は辞書と log.ts だけなので先に走る。
- 確かめていないこと: 本番ビルド（`vite build`）では HTML の module script が 1 つの入口チャンクにまとめられる可能性があり、その場合は初回の読み込み中（チャンクを取り終えるまで）日本語が見える。ビルドしての確認はしていない。気になるなら boot.ts から `import("../main")` で動的に読む形にすれば、小さな先行チャンクに分かれる。
- main.ts は `initI18n()` を呼ばない（boot が先に呼ぶ。2 回目以降は何もしない）。main.ts は `import * as i18n` で名前空間として読む。main には時刻・タクシーの `t` という局所変数があり、`t` を直接読むと oxlint の no-shadow が 4 件出たため。

# タイトル画面の言語ピッカーと 設定

- 右上に `日本語 | English | 中文`（それぞれ自分の言語で書く）の分割ボタン（`.panel.segmented`、時間帯のボタンと同じ見た目）と `⚙ 設定` を並べた（`.title-prefs`、`position: absolute`）。選んだ言語は `aria-pressed="true"`。中文 ボタンの title は「简体中文」。
- 設定 の先頭に「言語 / Language / 语言」の行（`#opt-lang`）を足した。この見出しだけは訳さない。読めない言語になっていても、自分の言語の名前で見つけられるように。
- タイトルの 設定 ボタンは `data-action="settings"` で、main.ts が全 `[data-action]` に付けるクリック処理から既存の `input.on("settings")` を通って `#settings` を開く。ダイアログの中身（画質パネル・操作設定の入力）は main() の途中で配線されるので、ボタンは `disabled` で始め、main.ts が `settingsDialog` の close 処理を付けた直後に有効にする（読み込み中は スタート と同じく待ちの見た目）。
- タイトルで開いたときは何も一時停止していないので、見出しの「一時停止中」を隠し、閉じるボタンを「閉じて再開」ではなく「閉じる」にした。CSS の `#loading:not([hidden]) ~ #settings` で切り替える（スクリプトは触らない）。`paused` は開くときに保存し閉じると戻すので、タイトルでは false → true → false になり、タイトルの描画（`state !== "playing"` の分岐が `paused` より先）にも スタート にも影響しない。

# キーの足し方

1. `src/i18n/ja.ts` に `"area.name": "日本語"` を足す。フェーズ 1 の区分は `title.` `loading.` `start.` `settings.` `graphics.` `toolbar.`（ラベル）`toolbarTitle.`（ツールチップ）`ai.reason.`。フェーズ 2 の分は辞書の末尾の 5 節（`// @@format` `// @@nav` `// @@law` `// @@game` `// @@talk` の目印の行で区切る）にある。区分の一覧は下の「フェーズ 2 で訳したもの」。
2. `en.ts` と `zh.ts` にも同じキーを足す。足さないと `Messages` 型で tsc が落ちる（余分なキーも落ちる）。`{slot}` は 3 言語で同じにする（テストが確かめる）。言語によって要らない値があるなら、キーを分ける（例: `unit.spokenKm` と英語の単数の `unit.spokenKmOne`、`clock.day` と `clock.dayHoliday`）。
3. 静的な HTML なら要素に `data-i18n="キー"` を付け、要素の中の日本語は ja.ts と同じにしておく（スクリプトが走る前に見える文。テストが空白を詰めて比べる）。文と子要素が混ざっているラベルは、文だけを `<span data-i18n>` で包む。
4. コードなら `t()`。切り替えで変わる必要がある画面の文は `setI18nText` か `bindText` にする。トーストのように数秒で消える文は `t()` だけでよい。毎フレーム書き直す HUD やナビのパネル、canvas は描くときに `t()` を呼べば切り替えに追従する。
5. 保存する文・AI や Y に渡す文は日本語で作る（`inJapanese(key, params)`）。画面に出すときに `retranslate()` で訳し直す（下の「記録は日本語のまま」）。
6. 鍵の名前は文に書かず `{key}` にし、`keyFor(input.layout, action)` から入れる（キー配置で変わるため）。

# 訳の方針

- 直訳しない。画面の言葉として短く書く。英語は米式綴り（color, license）、中国語は大陸の UI の慣習（全角の句読点、法令名は《》）。
- 法令名: 道路交通法 → Road Traffic Act / 《道路交通法》、東京都道路交通規則 → Tokyo Metropolitan Road Traffic Rules / 《东京都道路交通规则》。条項は `Art. 55(2)` / `第55条第2款`（項 → 款、号 → 项）。
- ロゴ「法令厳守 TOKYO OPEN DRIVE」は訳さない。副題で意味を伝える（英: "Drive Tokyo's 23 wards by the letter of the law — …"、中: 「严守交通法规，驾车畅行东京 23 区 —— …」）。
- SNS は「Y」のまま。実在のブランド名は出さない。
- 歩行者の声（sanoTTS-jp）は日本語しか話さないので、英・中では「Japanese」「日语」と書いた。
- ツールバーのボタンは 120 px（左右の余白 8 px、鍵との間 6 px、鍵 17〜28 px）で、ラベルに使えるのは約 70 px。13 px の文字で英字およそ 11 字、漢字 5 字を上限にし、テストで確かめる（"Destination" "Fast travel" "Time of day" が 11 字）。超えたら既存の `text-overflow: ellipsis` で切れる。撮影は "Screenshot"（10 字、F12 の鍵と並ぶと約 66 px で際どい）をやめて "Snapshot" にした。実際の幅はブラウザで測っていない。[^no-browser]

## 記録は日本語のまま、表示のときに訳し直す

違反の記録（localStorage に保存し、再読み込み後も読む）、その「内容」「場所」「日時」、Y の投稿者と会話 AI に渡す文は日本語のまま作る。画面に出すときに訳す。

- 書くとき: `inJapanese("violationDetail.speedSign", { limit, kmh, over })` は言語に関係なく日本語を返す。
- 出すとき: `retranslate(text, keys)` が各キーの日本語の型（`{slot}` を `(.+?)` にした正規表現）と照らし、合った型の値を取り出して今の言語で組み直す。値が日本語の語なら `nested` で訳す（通行止めの種類・車線の矢印・曲がり方は `violationWord.*` を「・」で分けて 1 語ずつ）。合わない文はそのまま出す。
- 違反名は `violationName(label)`: 固定の名前は `violation.label.*`（日本語が名前と完全に同じキー）、値の入る名前（速度超過（25km/h超過）、人身事故・付加点数（…）、放置違反金（…））は `violation.pattern.*` の型。フェーズ 2 より前に保存した記録も訳せる。
- 条項は `lawRef(article)`: 「道路交通法 第72条第1項前段」を法令名・条・の・項・号・前段/後段/ただし書・別表・（主題）に分けて組み直す。英語は "Road Traffic Act Art. 72(1), first sentence"、号は日本法令外国語訳の書き方でローマ数字（"Art. 119(1)(xiii)"）、「の」は "Art. 26-2"。中国語は「《道路交通法》第72条第1款前段」（項 → 款、号 → 项、の → 之）。一部でも読めない参照は日本語のまま返す（例: 「第52条：アイドリング・ストップ」のコロン入り）。
- Why not 記録に訳を保存する: 言語を切り替えると古い記録だけ別の言語で残る。Why not 記録をキーと値だけにする: Y と会話 AI が日本語の文を読むので、日本語の文は要る。両方持つより、日本語から戻すほうが古い記録も扱える。

## ナビ

- パネル・一覧・注意情報・レーン案内・交差点拡大図・車内ナビの「目的地まで」・地図の読み込み中・速度計の種類（規制速度 → Posted / 标志限速）を訳した。パネルは 264×352 の固定で、英語は短い言い方にした（"{min} min · {dist}" "Toward goal" "Continue to the goal"）。長さはテストで確かめる。
- 方位: 英語 N / NE / E…（向きの表示は "Heading NE"）、中国語は 北 / 东北 / 东 / 东南…（中国語は「东北」の順）。
- 交差点名: 日本語は「日比谷交差点」のまま。英語はデータの OSM の `name:en` を案内標識と同じ書き方（`signEnglish()`。"Hibiya" "Shinjuku Sta."）にし、無ければ日本語の名前から「交差点」を除いたもの。読みのデータは無いので、ローマ字を自分で作ることはしない。中国語は日本語の名前に「路口」（「日比谷路口」）。漢字は中国語の読み方で読まれ、中国語話者が日本の地名を呼ぶやり方と同じ。かなだけの名前（むらさき橋など）はかなのまま。[^osm-en]
- 道路名: 英語は OSM の `nameEn` を同じ書き方にし、番号は "Route 15"（国道）/ "Tokyo Route 304"（都道）。中国語は日本語と同じ（「晴海通り（都道304号）」）。
- 英語の声は看板の略語を言い換える（Sta. → Station、Ave. → Avenue、"-W." → West など）。
- 切り替えるとパネルの交差点名を作り直す（`prepare()` の入力に言語を入れた）。

### ナビの声

文は言語ごとに文全体の型で持つ（語順が違いすぎて部品からは組めない）。声は `localUtterance()`、速さ 1.05。端末の声の一覧にその言語が無ければ話さない（パネルは出る）。一覧の読み込み前（ページを開いた直後は空）は言語だけ指定してブラウザに任せる。Why not 既定の声で話す: 日本語の声で英語・中国語を読むと聞き取れない。同じ案内を繰り返さない判定は、日本語の文の正規表現ではなく、前置き（案内開始・再探索）に付けた印で行う。

## HUD・通知・ダイアログ

- main.ts のトースト 77 か所・通知 9 か所・自動運転の解除・タクシーの状態を `i18n.t()` に。通知の一覧（noticeLog.ts）は文の代わりに関数を持ち、切り替えると最新 10 件も訳し直す。
- 時計は `formatDay` と `formatClock`（土日・祝日の色の span はそのまま）。記録に残す時刻（`clockLabel`）は日本語のまま（`recordClock` が読み戻す）。
- 区名・町名・駅名・スポット名・人名はデータの日本語のまま。周りの言葉（「現在地: 」「発見」など）とスポットの種類（`mission.category.*`）は訳す。
- 警察官の声: speechSynthesis で話すときは選んだ言語で話す（声が無ければ話さない）。sanoTTS-jp で話すときは日本語のまま話し、英・中では訳をトーストで出す。
- 指導員（一日の終わりの運転のアドバイス）: 日本語の指示文は変えず、英・中では指示文を英語・中国語にして、その言語で答えるよう頼む。今日の違反の一覧は日本語のまま渡す。
- 日本語のまま残したもの: 判子の絵（逮捕・違反・確認標章・放置違反金。世界の中の絵）、自動運転タクシーの屋根の表示（迎車・賃走・支払・回送。実物の東京のタクシーと同じ）。スマホのメーターの表示は訳した（Hired / Pay、载客 / 支付）。

## 切符

[交通切符の様式](ticket-forms.md)は日本語のまま描き、英・中では様式の上に要約の枠（`aside.ticket-summary`、青切符は青・赤切符は赤の左の線）を出す。中身は、何の書類か（Traffic Violation Notice (blue ticket) / 交通违章告知书（蓝单）、赤切符は刑事手続の告知票）、違反ごとの名前・条項・点数・反則金、合計、納め方と期限（告知の翌日から 7 日以内に、納付書で銀行・郵便局の窓口。コンビニは不可。赤切符は納めるものが無く後日呼び出し）、下が日本語の原本であること。日本語では枠を出さない（今まで通り）。ダイアログの見出しとボタンも訳した。

## テレビ

- 局名は架空のまま訳した（げんしゅテレビ → Abide TV / 守法电视台、天気・自然の局も同じ型）。実在の放送局名が出ないことをテストで確かめる。
- 「走行中は映像を表示できません」→ "No picture while driving" / 「行驶中无法显示画面」。
- 受信料のパロディ: "About Your Viewing Fee (fiction) / Abide Broadcasting's fee is paid in one way: obeying the law. / Violations today: n × ¥0 = ¥0 / We look forward to your payment of zero violations." / 「收视费通知（虚构）… 期待您以"零违法"缴费。」
- ニュースの読み上げは英・中では `localUtterance()`（en-US / zh-CN）、日本語は今まで通り sanoTTS-jp。英語の時刻は 12 時間（"The time is 2:05."）、場所は区の英語名（"You're near Chiyoda City."、23 区の外は言わない）。
- canvas の文字に最大幅を付け、中国語では PingFang SC などの簡体字のフォントを先にした。

## 歩行者との会話と 119・110

- 定型応答は訳した文を表示し、声（sanoTTS-jp）は日本語の原文で話す（`templateLine` が `{ text, ja }` を返す）。会話 AI の返答は英・中では声を出さない（日本語の原文が無い）。声のスイッチは "Japanese voice" / 「日语语音」、ツールチップで日本語しか話さないことを書いた。
- 会話 AI（Gemma）への指示: 英・中では「英語で答える」「用简体中文回答」を足し、日本語の声のための「英語やアルファベットを避ける」は外す。日本語の指示文は変えていない。禁止語の判定に英・中の短い表を足した。質問の種類（おすすめ・天気・場所・交通）の判定も英・中の言い方を拾う。
- 119・110: 指令員の台詞・早押しの返答・入力欄・「終話」を訳した。声は台本の台詞だけ日本語の原文で話す。指令員役の AI にも返答の言語を指示する。出動の判定は英・中の文でも働く。
- 模擬通報の注意書き（本物の 119・110 にはつながらない、いたずら通報は犯罪 = 軽犯罪法 第1条第16号）は意味を落とさずに訳した（"Prank calls are a crime in Japan (Minor Offenses Act Art. 1(xvi))."）。

## 日本語が変わった所

鍵の名前を `keyFor()` から入れるようにしたため、古い鍵を書いていた 4 か所の日本語が直った: 免許停止中に乗るときの「もう一度 F」→ Q、事故の表示の「スマホ（P）」→ F、📱 ボタンの title（P）→ F、自動運転中の表示の「（O・…）」→ WASD では J、CCD では A。

# 落とし穴

- `data-i18n` を子要素のある要素に付けると、子要素ごと消える。`<label>キー配置 <select>…</select></label>` のような所は文だけを `<span>` で包んだ。`.control-options label` は grid、`.check` は flex なので、包んでも並びは変わらない（テキストも span も 1 つの項目になる）。
- `:lang(zh)` を全要素に当てるとフォントが継承ではなく各要素に直接付き、切符や Y の明朝・手書きのフォントを上書きしてしまう。body だけに当てた。
- `<html lang>` を `en` にすると、日本語のまま残した区名・町名などを読み上げソフトが英語の発音で読む。
- `{slot}` は 3 言語で同じでなければならない（テスト）。英語だけ単数・複数で文が変わるときや、休日だけ文が変わるときはキーを分ける。
- main.ts は `t` を局所変数（時刻・タクシー）に使っているので `import * as i18n` で読む。tvRules.ts・naviTv.ts も音のコードの `t` とぶつかるので同じ。
- `retranslate` は先に合った型を使う。値の無い型（`violationDetail.closedRoadAny`「通行禁止の道路に進入」）は、同じ文に合ってしまう値のある型（`violationDetail.closedRoad`「{what}の道路に進入」）より辞書の前に置く。逆だと「通行禁止」が値として取り出され、`violationWord.*` に無いので日本語のまま残る。
- 依頼された時点で始まっていた別の作業（Y）と同じファイルを触らないよう、辞書はファイルの末尾の節ごとに分け、追加は 1 回の読み書きで済ませた。
- テストは DOM を持たない（vitest の環境は node、jsdom は入れていない）。applyI18n は属性と textContent しか使わないので、偽の要素で確かめた。
